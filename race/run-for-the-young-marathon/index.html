Course

Most of the event runs on gravel trail. The 10 km, half marathon and marathon follow the Warburton Trail, while the 5 km and 2.5 km kids run circle Lilydale Lake. Drink stations sit roughly 3 to 4 km apart across all distances.

About

The Run for the Young Marathon is an annual charity fundraiser run by the Bridge Builders Youth Organisation to raise funds for local community work. The event offers multiple race distances and provides a great day out for the whole family.
