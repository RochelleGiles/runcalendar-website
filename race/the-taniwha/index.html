Course

Point-to-point along the Waikato River Trails, with separate start lines per distance feeding a single finish and event base. The route covers native bush, exotic forest, boardwalks over wetlands and single track. The organiser notes there is no race-morning registration at the finish, only at the start lines.

About

The Taniwha is a point-to-point trail event on the Waikato River Trails in the central North Island of New Zealand, run by Total Sport. Runners and walkers choose 7 km, 16 km, 22 km or 42.2 km, with mountain bike and duathlon options alongside. Each distance has its own start line and all finish at a single event base.
