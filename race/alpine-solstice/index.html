Course

Both races start and finish at Swampy Lakes Sno Park outside Bend. The 55K is a loop on Central Oregon single-track passing Tumalo Falls, stated as 90 percent single-track and 10 percent gravel road, with three fully stocked aid stations. Start times have historically been 7:00am for the 55K and 9:00am for the half marathon.

About

Welcome to Alpine Solstice! Set on one of the longest days of the year, this early summer race is a great way to start off mountain season. Classic Bend smooth single track awaits you in June! Join us for a fun day in the Cascades as we welcome in summer. A new 55K course has been added that runs by Tumalo Falls.
