Course

Held inside Kinloss Barracks, the 5K, 10K and Ray Hughes Half Marathon run entirely on tarmac and concrete runways and taxiways with minimal elevation change. The Backyard Ultra runs 4.1-mile loops on the hour: an 80% off-road day loop of rough grass, gravel and sand, and a fully paved night loop. A 1K fun run uses a taxiway beside the race village.

About

The Kinloss Running Festival is a multi-distance road race weekend in the Moray village of Kinloss, Scotland, offering 5K, 7K, 10K and 13-mile options for runners of different levels.
