About

The 9th Annual Oracle Rumble is a trail running event near Oracle, Arizona, featuring mostly single-track trails through Oracle State Park and sections of the Arizona National Scenic Trail. The course is constantly rolling with breathtaking views of the Santa Catalina Mountains.
