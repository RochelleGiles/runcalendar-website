Course

Courses start and finish at an event base at Te Haruhi Bay and cover farmland, beach, headlands and bush, mixing gravel road, single track, beach and grass. The long and super long courses include a long coastal section requiring rock hopping. Drink stations are placed on each course.

About

The Auckland Trail Run & Walk Series event at Shakespear Regional Park is part of an annual Winter series organised by Trail Events NZ. Each event offers multiple distance options in stunning locations within one hour of central Auckland.
