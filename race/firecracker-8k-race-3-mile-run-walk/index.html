Course

Both courses start and finish at Agawam Park in Southampton village, on USATF-certified routes. An 8K run and a 3-mile walk are offered, setting off at 7:30 AM.

About

The Firecracker 8k Race & 3 Mile Run / Walk is an annual event organized by the Southampton Rotary Club to benefit the Southampton Rotary Scholarship Fund.
