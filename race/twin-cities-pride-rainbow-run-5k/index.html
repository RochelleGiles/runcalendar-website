Course

Point-to-point 5K run down Hennepin Avenue following the Twin Cities Pride parade route, starting at BF Nelson Park in northeast Minneapolis and finishing at MCTC. City streets throughout, run ahead of the parade with spectators lining the course. A short Kids Rainbow Dash covers two blocks of Hennepin.

About

The Twin Cities Pride Rainbow Run 5K includes a Kid's Rainbow Dash for younger runners, with the option to participate virtually from anywhere for those who can't make it to Minneapolis.
