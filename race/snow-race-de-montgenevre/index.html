About

The Snow Race de Montgenevre is an exhilarating winter running event set against the breathtaking backdrop of the French Alps. Runners will navigate a challenging course through snowy landscapes, offering a unique and thrilling racing experience. This annual event is a must for any adventurous trail runner seeking an unforgettable mountain adventure.
