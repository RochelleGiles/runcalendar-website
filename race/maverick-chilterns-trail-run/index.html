Course

Looped routes starting and finishing at Princes Risborough School in the Chiltern Hills, linking sections of the Ridgeway and Chiltern Way. Punchy climbs on chalky trail, ancient beech woodland singletrack, bridleways and sweeping ridgelines. Distances run 8km, 14km, 24km, 42km and a 50km ultra, with aid outposts on the longer routes.

About

The Maverick Chilterns Trail Run is a scenic trail running event set in the beautiful Chilterns countryside. Runners will experience stunning views, challenging terrain, and a welcoming atmosphere as they tackle this unique trail race.
