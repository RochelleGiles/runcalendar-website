Course

Run at Chain O'Lakes State Park near Albion, Indiana, over repeated loops of forest trail. The organiser calls it easy enough for a first trail race but technical enough to reward seasoned trail runners. A single-loop option of about 10 miles runs alongside the 50K and the three-person relay.

About

The HUFF 50K Trail Run and Relay takes place at Chain O'Lakes State Park in Albion, Indiana each December. Runners can enter the 50K solo or as part of a relay team covering the same looped trail course.
