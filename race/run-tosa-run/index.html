Course

Starts at 69th Street and North Avenue and weaves through the Tosa East Towne neighbourhood streets between 74th and 62nd Streets. A paved road course on tree-lined residential streets. An untimed half-mile kids run loops a single city block.

About

Run Tosa Run is a 5K run/walk and untimed half-mile kids' run through the beautiful tree-lined streets of the Tosa East Towne neighborhood, benefiting Ronald McDonald House Charities Eastern Wisconsin.
