Course

About

The Cocoa Classic 5k Run is an exciting event for all participants! It's a fun and fast race on a USATF-certified course that can be a personal challenge and a chance to qualify for the Peachtree Road Race. Get ready to put on your running shoes and have an unforgettable experience filled with excitement, accomplishment, and a little sweetness!
