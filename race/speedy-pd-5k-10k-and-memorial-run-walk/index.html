Course

Both the 5K and 10K are USATF certified and run entirely on paved roads in Tuttle Creek State Park. The 5K is very flat to the finish, the 10K flat and shaded throughout, and both take in lake views and are stroller friendly. A half-mile memorial walk and run is held alongside.

About

The Speedy PD Race for Parkinson's Disease is an annual 5K and 10K at Tuttle Creek State Park near Manhattan, Kansas, hosted by Meadowlark. Both courses are USATF certified and fully paved, and a half-mile memorial walk is held alongside. Proceeds support Parkinson's programmes.
