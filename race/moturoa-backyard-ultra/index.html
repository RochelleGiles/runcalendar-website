Course

Backyard ultra on Rough Island (Moturoa) near Nelson. Runners repeat a 6.706 km loop, each lap starting on the hour and needing to be finished inside 60 minutes, and the race runs until only one competitor remains. The field is capped at 250 entries.

About

The Moturoa Backyard Ultra takes place at Rough Island in Nelson. Participants repeatedly run laps of a 6.706km loop course, starting every hour on the hour, with the event continuing until only one runner remains.
