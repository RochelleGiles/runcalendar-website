About

The USA Beach Running Championships is a premier running event held annually in Cocoa Beach, Florida. Runners can choose from 5K, 10K, and 15K distances, with the option to compete in a barefoot division. The low-tide, out and back course on hard-packed sand offers a unique and scenic running experience.
