About

The Spring Lake Five Mile Run is a USATF-certified 5-mile road race held annually in Spring Lake, New Jersey, attracting up to 12,500 participants. Founded in 1977, it supports local charities through proceeds and features a fast, flat course along the Jersey Shore.
