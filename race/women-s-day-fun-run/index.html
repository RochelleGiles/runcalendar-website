Course

A flat, fast out-and-back on the Eaton Trail, a paved bike path through Woodward Park in Fresno. Start and finish are at the Mt. View Shelter. Run in the evening from 5:00 PM over 5K and 2 mile, with a kids run to follow.

About

An evening run at Woodward Park in Fresno marking Dia de la Mujer, run under the banner "We Run the World". The 5K and 2 mile set off together at 5:00 PM on the paved Eaton Trail, with a kids run afterwards. All participants are welcome, not only women.
