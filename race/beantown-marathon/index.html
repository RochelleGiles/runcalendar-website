Course

Multi-lap marathon held entirely within Bare Cove Park in Hingham, Massachusetts, starting at 7:00am. It is run as a Boston Marathon qualifier with pace-specific start waves so runners group by target finish time. Personal bottle and fuel stations are provided, which runners stock themselves.

About

The Beantown Marathon is a marathon-only race held each September in Hingham, Massachusetts, on the South Shore. It is a popular late-summer option for runners chasing a fast finish before autumn racing season.
