About

The Sandy Running Festival is a unique fun run that challenges participants to run on sand while supporting life-saving community development projects in South Sudan and Northern Uganda. Runners can expand their personal limits and make a meaningful impact by participating in this inspiring event that connects physical challenge with humanitarian support.
