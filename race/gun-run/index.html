Course

A two-day event on the Atlantic seaboard. The 17km trail run starts at Van Riebeeck Park in Oranjezicht; the 10km, 5km fun run and 5km pet walk start on Fritz Sonnenberg Road in Green Point. All races finish on the Green Point Common opposite the Green Point Cricket Club. The half marathon runs on the Sunday with refreshment points every 3km.
