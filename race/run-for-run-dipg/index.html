About

Run for RUN DIPG in Redhead, NSW is a must-attend event for runners looking to support a meaningful cause. This community-driven race raises vital funds for childhood brain cancer research, with participants enjoying a scenic coastal course along the beautiful Redhead Beach. Join fellow runners in making a difference for this important initiative.
