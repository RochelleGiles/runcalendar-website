About

The 14th Annual Spring Fever is a rewarding event for novice and experienced athletes set against Table Mountain and Colorado foothills. It features 5K, 10K, and half marathon courses along Ralston Creek Trail and Blunn Reservoir, benefiting UpRoot Colorado and serving as a BOLDERBoulder qualifier.
