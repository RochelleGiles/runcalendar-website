About

The Juneteenth 2.5 Mile Run celebrates Juneteenth with a fun 2.5 mile run/walk at Glass City Metropark in Toledo, OH. It includes a free kids 1K run starting at 5:30 pm, followed by the main event at 6:19 pm.
