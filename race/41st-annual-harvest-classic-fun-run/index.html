About

The Harvest Classic Fun Run features an 8K run or wheelchair race, 2-mile run or walk, 1-mile non-competitive race, food, prizes, entertainment, vendor booths and a school competition. All participants receive a wicking material race shirt, free admission to the Harward Rec Center on race day and a chance to win fantastic prizes in the post-race drawings. Prizes are also awarded for top race finishers.
