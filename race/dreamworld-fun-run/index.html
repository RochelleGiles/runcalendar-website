About

The Dreamworld Fun Run features a unique themed 5km and a kids 2km distance. The 5km course snakes around both Dreamworld and WhiteWater World, while the 2km Junior Dash weaves through Dreamworld's themed kids precincts with bubbles, foam, smoke, snow, and a colour zone. Walkers are welcome, and every entrant gets a Finisher Medal.
