Course

Trail races at O'Bannon Woods State Park near Corydon, Indiana. The 50K runs a rugged, technical 24-mile loop of the Adventure Hiking Trail with about 4,500ft of climb; a 6.6-mile loop with roughly 700ft of gain is run once or twice for the half marathon, and a 5K carries about 500ft.

About

New Hope Wesleyan Ultra Trail Run is a 50K trail race near O'Bannon Woods State Park in the hill country of southern Indiana. The course crosses the wooded, rolling terrain of the Harrison-Crawford region on trails based out of New Hope Wesleyan Church.
