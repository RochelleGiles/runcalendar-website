About

This ORRC event at Champoeg State Park features 10K, 20K, and 30K races through forests, fields, and wetlands, combining history, nature, and recreation. Participants can complete one loop for 10K, two for 20K, or three for 30K, with a kids' run and eco-friendly practices encouraged.
