About

The YMCA St. Patrick's Day Run and Leprechaun Loop brings runners through downtown Boise each March, with 5K and 5-mile options presented by ICCU. It's a longtime Treasure Valley YMCA tradition that draws a festive, green-clad crowd to the city center.
