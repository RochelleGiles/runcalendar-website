Course

Adult races start at the Summit Road start line above Akaroa; the Kids Dash starts at Akaroa Recreation Ground. The marathon starts at 9:00am, the half marathon and 10 km at 9:30am. Aid stations on course provide water, electrolytes and nutrition. The organiser pages do not state course shape, surface or finish location.

About

Explore the stunning Akaroa Harbour on the inaugural Run Akaroa. This scenic event features courses designed to showcase the breathtaking natural beauty of the region near Christchurch, New Zealand. With stunning harbour views and a picturesque setting, Run Akaroa promises an unforgettable running experience.
