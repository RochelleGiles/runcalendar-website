About

The Prague Half Marathon is a must-run event for any avid runner. Weaving through the historic streets of the Czech capital, this scenic course showcases the city's stunning architecture and vibrant atmosphere. With a reputation for exceptional organization and an enthusiastic crowd, this event is a favorite among international runners seeking an unforgettable European running experience.
