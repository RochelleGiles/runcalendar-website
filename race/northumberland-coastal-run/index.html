Course

An approximately 14-mile point-to-point run from Beadnell Harbour, finishing on the beach at Alnmouth. The route follows the Northumberland coastal path as closely as possible, passing Dunstanburgh Castle, Craster, Howick Sands and Boulmer. Underfoot it mixes sand, trail and road.

About

The Northumberland Coastal Run is a 14-mile trail race organised by Alnwick Harriers, following the coastline of Northumberland in the north-east of England, with much of the route running along the shore.
