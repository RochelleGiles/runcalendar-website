Course

Starts and finishes at Spring Hill Elementary School on Bradford Square, Fayetteville. An evening programme: the 1 mile colour fun run goes at 5:00pm and the 5K at 5:30pm. Medals go to the first 200 5K finishers. The organiser publishes Garmin course files but states no surface or aid-station detail.

About

The Spring Hill Sun Run is a community race held at Spring Hill Elementary School to benefit the school. It features a 5K run/walk and a 1-mile fun run with food trucks, prizes, and live music.
