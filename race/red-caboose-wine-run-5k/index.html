Course

A two-lap cross-country style route around the grounds of Red Caboose Winery and Vineyards. Footing is uneven in places but the course is suitable for both runners and walkers, and finishes at the winery.

About

The Red Caboose Wine Run 5K is a unique event that combines a scenic 5K run/walk with the opportunity to enjoy a refreshing glass of wine at the finish line. Set in the beautiful vineyards of the Red Caboose Winery, this event offers a fun and festive way to celebrate the season.
