Course

The 5K and 10K both run on Constitution Trail, with the start and finish outside Keg Grove in Bloomington. The race goes off at 5:15 PM, and walkers are welcome to set out before the main start.

About

The Fat Tuesday 5K/10K Run is a community road race hosted by the Lake Run Club at Keg Grove in Bloomington, Illinois, offering both 5K and 10K distances.
