Course

Runs alongside the Yarra River and into Warrandyte State Park before returning to the Festival Village to finish. The course is undulating and picturesque. Distances run from a 2.2km and an under-8 event up through 5km, 10km and 15km to 21km.

About

Run Warrandyte takes place each March in the bushy river town of Warrandyte, north-east of Melbourne, with courses through the surrounding state park and along the Yarra River.
