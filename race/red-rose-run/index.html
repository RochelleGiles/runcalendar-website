Course

Five-mile road race starting and finishing on North Queen Street in downtown Lancaster, touring the city streets before a loop through Lancaster County Park's rolling hills. USATF-certified and run as a Mid-Atlantic Championship and Grand Prix circuit race. A kids' run is held alongside.

About

The Red Rose Run is an annual 5-mile road race through the streets of Lancaster, Pennsylvania, run since the 1970s and now marking its 50th anniversary. It remains one of the city's longest-running road races.
