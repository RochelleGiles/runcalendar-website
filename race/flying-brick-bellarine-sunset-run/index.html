Course

A light coastal trail event on the Bellarine Peninsula between Portarlington and St Leonards. The half marathon is an out-and-back from Portarlington pier; the 10.5 km runs one way from St Leonards pier to the Portarlington finish with bus transport included. A 4 km Bully Buster completes the programme.

About

The Flying Brick Bellarine Sunset Run offers a half marathon, 10km and 4km fun run and walk on coastal trails in Portarlington, on Victoria's Bellarine Peninsula.
