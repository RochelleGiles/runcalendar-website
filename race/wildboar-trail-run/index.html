About

The newest beast in the Trailsplus mountain trail running adventures. Set in the rugged beauty of Brisbane Ranges National Park, this thrilling event invites you to run wild through stunning native bushland, twisty single tracks, and challenging climbs that will put your trail legs to the test. Join us for another memorable adventure and soak in the raw Aussie wilderness, WildBoar has something for everyone – from 10km fun run to the epic 50km ultra.
