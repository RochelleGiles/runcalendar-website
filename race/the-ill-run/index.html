About

The Ill Run is a running event organized by Team Com and the Communauté de Communes du Centre Haut Rhin. The event features a semi-marathon, 10K, and 5K 'pink' race, with all finishes in Ensisheim. The courses run along the banks of the Ill River and through the 9 villages of the Communauté de Communes du Centre Haut Rhin.
