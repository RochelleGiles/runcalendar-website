Course

An out-and-back run starting on the path opposite the DoubleTree by Hilton on Barrett Drive, Alice Springs. The route follows Barrett Drive, drops down the causeway and returns up South Terrace, with 2.5km and 5km options on the same course.

About

Amanda's Fun Run is a free community run and walk staged by the Alice Springs Running and Walking Club, with 2.5 km and 5 km options on the River Trail. It is held in memory of a local runner and raises money for ovarian cancer awareness and research.
