About

The Dolomyths Run Sellaronda Ultra is a captivating trail running event set against the breathtaking backdrop of the Italian Dolomites. Challenging runners with a stunning 50-mile loop around the iconic Sella Massif, this race offers a unique opportunity to immerse yourself in the region's stunning alpine landscapes and rich cultural heritage.
