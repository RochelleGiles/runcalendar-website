About

Transgrancanaria HG is a thrilling ultra-running event set against the stunning backdrop of the Canary Islands. Runners will tackle a challenging course through volcanic landscapes, offering breathtaking views and a true test of endurance. This prestigious race attracts top athletes from around the world, making it a must-do event for any serious trail runner.
