Course

An evening 10K on the pedestrian and cycle paths of the old M48 Severn Bridge between England and Wales, run between the estuary and the sky. The road-closure half marathon no longer runs because permission to close the bridge has been refused, so the race now uses the bridge's side paths.

About

The Severn Bridge 10k is an evening race that takes place on the pedestrian accessways of the iconic 'old' Severn Bridge, allowing runners to experience running between sea and sky over this historic landmark.
