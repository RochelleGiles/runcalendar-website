About

The Rasselbock Run Winter edition takes runners on a scenic journey through the enchanting Sherwood Pines Forest in Nottinghamshire. Immerse yourself in the serene winter landscape as you navigate the trails and paths of this historic woodland, making for an unforgettable running experience. Whether you're a seasoned trail runner or new to the sport, this event promises an exhilarating challenge amidst the beauty of nature.
