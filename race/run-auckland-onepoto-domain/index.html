Course

Lapped course at Onepoto Domain, Northcote: the 5km is one lap and the 10km two laps of the same circuit. Roads are open to normal traffic with no road closures, and participants must run on the footpath at all times.

About

Run Auckland at Onepoto Domain is part of the Run Auckland Series, taking runners on a scenic tour of Onepoto Domain with views over the surrounding Auckland landscape. It is a community-focused run suited to seasoned marathoners and casual joggers alike.
