Course

The 5 mile, 5K and 1.25 mile races all start and finish at the Iroquois Amphitheater on Amphitheater Road and run inside Iroquois Park. Park roadways stay open to golf course traffic, so runners are asked to use the pedestrian path on the back side of the park. The start is at 9:00am.

About

The 45th annual Thanksgiving Day run hosted by the Iroquois Hill Runners club in Louisville, Kentucky, with 5K, 5-mile and 1.25-mile options. The club takes its name from hilly, wooded Iroquois Park in south Louisville.
