Course

The 10K, 5K and Memorial Mile are run on the tree-lined streets of Ridgewood, starting and finishing at Veterans Field. All courses are USATF-certified and each includes a push-rim wheelchair division. A fun run is also held.

About

The Ridgewood Run is a spirited day of multiple outdoor running events promoting health, wellness, family, and community, produced annually by the North Jersey Masters Running Club since 1976 on Memorial Day in Ridgewood, NJ. It features USATF certified courses including a 10K, 5K, Elite Mile, Community Mile, and Fun Run.
