About

The Second Annual Hustle for Habitat 5K is a fun-filled running event for all levels held at Hoff Woods Park in Westerville, Ohio. The event supports the Westerville Habitat Partnership, a non-profit organization that provides housing solutions for families in need through fundraising and community collaboration.
