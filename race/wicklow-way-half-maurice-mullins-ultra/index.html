About

The Wicklow Way Half/Maurice Mullins Ultra is a challenging and scenic trail running event set amidst the stunning landscapes of Ireland's Wicklow Mountains. Runners will tackle a half-marathon distance along the famous Wicklow Way, immersed in the region's natural beauty and rich history. This unique event honors the memory of Irish ultrarunning legend Maurice Mullins, making it a must-do for endurance athletes seeking an unforgettable adventure.
