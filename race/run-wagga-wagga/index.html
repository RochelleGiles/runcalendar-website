About

Run Wagga Wagga is a community running event set along the picturesque riverbank of the Murrumbidgee in New South Wales. Runners of all levels can enjoy the scenic views and friendly atmosphere as they make their way through this beautiful regional area. Whether you're looking for a fun local race or a chance to explore a new part of Australia, Run Wagga Wagga promises an unforgettable running experience.
