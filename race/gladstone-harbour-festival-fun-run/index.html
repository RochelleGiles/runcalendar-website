About

The Gladstone Harbour Festival Fun Run is a must-do event for runners in Australia. Set against the stunning backdrop of the Gladstone Harbour, this annual Good Friday race offers a picturesque course and a lively festival atmosphere. Whether you're a seasoned runner or just starting out, this community-driven event promises an unforgettable experience.
