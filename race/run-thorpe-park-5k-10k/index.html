Course

Run entirely inside THORPE PARK Resort on a 5K circuit beneath the rides, starting and finishing within the park grounds. The 5K covers one loop and the 10K two. Both races start at 8:30am before the park opens to the public, and entry includes full-day access to the resort.

About

A road race circuit around Thorpe Park in Surrey, run before the theme park opens for the day. The 5K and 10K courses loop the resort's lake with the park's rides visible throughout.
