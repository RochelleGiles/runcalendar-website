Course

The race starts at Waco Fire Station 1 on Peach Street. Start times are 8:30 a.m. for the 1-mile fun run and 9:00 a.m. for the 5K. The event is run as a departmental challenge between the Waco Fire and Police departments. Route shape, surface and aid stations are not published.

About

A family-friendly running event featuring a fun competition between the Waco Fire and Police Departments. Race proceeds benefit both the Waco Professional Firefighters - IAFF 478 and The Waco Police Association.
