Course

The half marathon, 10K and 2K Kids Dash start at Rond Terrace, with the 5K starting separately at King George Terrace, on a course passing Old and New Parliament House. A complimentary shuttle bus runs from the finish area to the 5K start.

About

The Canberra Times Run Canberra is an annual road running event in Australia's capital, with half marathon, 10K, 5K fun run and a kids' 2km on offer, drawing runners of all abilities from across the ACT each November.
