Course

Waterfront 5K starting and finishing at Margaret Upton Arboretum in St Joseph, running past Silver Beach and Lions Park Beach, along the Howard Recreational Trail and through the Whirlpool Compass Fountain. Sealed paths and sidewalks with views of the St Joseph River and Lake Michigan. A 1K kids' fun run uses paved sidewalk on the same site.

About

Alex's Duck Duck Run is a scenic 5K run/walk and 1K kids' fun run held in St. Joseph, Michigan, supporting children battling cancer. The 5K course takes participants along the St. Joseph River and two Lake Michigan beaches, including Silver Beach, Lions Park Beach, and the Howard Recreational Trail.
