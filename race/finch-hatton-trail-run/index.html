Course

Held on the Finch Hatton MTB trails off Anzac Parade, mixing flowing single track with fire road. Rolling downhills and short punchy climbs, with valley views. Runners pass back through the start/finish every 6km for water and nutrition, so the longer distances are repeated loops of the same trail network.

About

The Finch Hatton Trail Run is a scenic running event set in the beautiful Finch Hatton Gorge in Queensland, Australia. Runners will experience a challenging course that winds through lush rainforest and past stunning waterfalls, offering a truly unique and memorable running experience.
