About

Vincent's Run is an annual 5K run and 1 Mile Fun Walk held in honor of Vincent 'Vinny' Gagliardi, who tragically passed away in an automobile accident. The event supports the Vincent R. Gagliardi Foundation's memorial scholarship and promotes seat belt safety with the message #buckleupforvincent.
