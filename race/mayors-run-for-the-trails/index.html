Course

A 5K run and walk starting at the Terra Park Amphitheater in Johnston, on the park's trail network around the lake. Walkers set off at 9:15am and runners at 9:30am, with kids' fun runs of 100 metres and 0.62 miles beforehand. The Mayor hands finisher medals to every participant.

About

Mayor's Run for the Trails is an annual community 5K in Johnston, Iowa, held along the city's network of paved trails with support from the mayor's office. A kids' fun run takes place alongside the main event, making it a family-friendly fixture on the local calendar.
