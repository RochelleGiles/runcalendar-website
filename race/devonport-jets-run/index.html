About

The Devonport Jets Run is a lively summer evening event held in the scenic coastal town of Devonport, New Zealand. Runners of all levels are invited to join the local Devonport Jets club for a fun, social run through the picturesque streets and seaside promenade. This weekly event is a great way to experience the community spirit and natural beauty of this charming Kiwi destination.
