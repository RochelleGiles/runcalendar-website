About

Born to Run - New Orleans is a 5K and half-mile fun run starting at the Bonnabel Boat Launch in Metairie, open to runners, walkers, and strollers. The event benefits Woman's New Life Clinic, which provides life-affirming counseling and medical care for women facing unplanned pregnancies in the Greater New Orleans and Baton Rouge areas.
