About

The Potter's House Steve Proffitt Legacy 5K and Fun Run is a Springfield, Missouri run and walk in which students, alumni and community members raise money for the Potter's House coffee shop and its work with college students. Entries include a 5K run/walk, a college student group category, a free children's 5K and a virtual option.
