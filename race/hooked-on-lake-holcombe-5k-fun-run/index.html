About

The Hooked on Lake Holcombe 5K Fun Run is a run/walk event organized by Holcombe UMC in the Lake Holcombe resort area, featuring a mostly flat route through Holcombe with road and trail terrain. The event includes a 90-yard kids' dash, games, food, beverages, and access to local attractions like camping, boating, and fishing.
