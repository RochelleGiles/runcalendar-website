About

The Cranford Pizza Run 5K is a fun run or walk event on a scenic 5K course through Nomahegan Park in Cranford, NJ. Participants receive a shirt, finisher's medal, and a slice of pizza, with awards for top finishers and costumes, benefiting breast cancer charities.
