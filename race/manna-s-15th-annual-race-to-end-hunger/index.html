Course

The 5K and 10K start and finish at Knapp Elementary School on Knapp Road, Lansdale, with the 10K run as two 5K loops. A separate 1 mile fun run follows a shorter route. The race is professionally timed.

About

The Race to End Hunger is Manna on Main Street's biggest annual fundraiser, with proceeds from the event helping Manna provide programs and services for those in need in the North Penn region.
