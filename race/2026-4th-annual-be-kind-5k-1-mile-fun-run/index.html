Course

Start and finish at the same point inside Holicong Park, 5143 York Road, Doylestown, Pennsylvania. The 5K is a certified out-and-back that leaves the park onto roads closed for the race; a one-mile fun run goes off half an hour earlier. No aid station detail is published.

About

The 4th Annual Be Kind 5K & 1 Mile Fun Run is a community event that raises money for the Kin Wellness and Support Center, which provides free services to Bucks County cancer patients and their families.
