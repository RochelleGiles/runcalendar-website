About

The 22 Degree Run & Plunge is an annual event that features a 2.2-mile run/walk and a polar plunge in the Great South Bay. The event is held to raise awareness and support for suicide prevention, with proceeds benefiting Operation VEST, a non-profit organization dedicated to helping veterans and first responders.
