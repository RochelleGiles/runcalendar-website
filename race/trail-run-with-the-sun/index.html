Trail Run with the Sun

Erie, Pennsylvania · United States

Course

Self-supported sunrise-to-sunset lapped event on a 2.25-mile loop around the former Gospel Hill Golf Club, owned by Penn State Behrend. Surface is grass, mud and gravel path with side-hill, open fields and two hills. Runners complete as many laps as they choose between 5:44am and 8:59pm. No aid stations. Start at 4415 Steimer Rd, Erie.
