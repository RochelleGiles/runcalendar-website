Course

Start and finish at Bonna Point Reserve, Kurnell, with all courses run on the flat sealed foreshore path along Botany Bay. The 10K is a two-lap out-and-back; the 6K and 3K are single out-and-backs. The aquathlon pairs a 750m swim at Silver Beach Baths with a 4km run.

About

Shire Run Carnival is a community running festival at Kurnell on Botany Bay, with distances from a 1.5km kids dash to a 10km run/walk alongside a linked aquathlon and swim events.
