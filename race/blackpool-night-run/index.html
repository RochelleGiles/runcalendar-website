About

Blackpool Night Run is a free event that takes place on the Tower Festival Headland in Blackpool, UK. Runners will have the opportunity to run through the iconic Blackpool Illuminations, making this a unique and special experience. The event aims to raise funds for the Brian House Children's Hospice, which provides care for babies, children, and young people with life-limiting and life-threatening conditions.
