Course

Run on the Granite Town Rail Trail between Brookline and Milford, following a former late-19th-century railroad bed. The layout is a 15-mile out-and-back that longer entries repeat, mostly straight, flat and well groomed with a single hill; about one mile of each 15-mile lap is paved. Aid stations are set along the route.

About
