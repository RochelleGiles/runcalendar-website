Course

Starts and finishes at the Ocean Grove Golf Club car park, 9 Guthridge Street, following the Barwon River riverside route. Run as a handicap start, so slower runners set off first and the field converges at the finish. Entries close at 8:30am on race morning for an 8am event window.

About

The Geelong Cross Country Club's Ocean Grove Riverside 8km is run in a handicap format. Non-club members can take part as invitation runners for a slightly higher entry fee.
