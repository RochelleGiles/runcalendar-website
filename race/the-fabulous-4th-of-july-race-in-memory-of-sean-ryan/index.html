Course

An accurately measured 4K (2.49 miles), flat, starting and finishing on the boardwalk at Laurelton Boulevard in Long Beach, New York. Baby strollers are not permitted on the course. A 1K fun run for children 15 and under is run untimed.

About

The Fabulous 4th of July Race in Memory of Sean Ryan is an annual event held in Long Beach, New York. The race features a 1 Kilometer Fun Run and a 4 Kilometer Run, with awards for top finishers in various age categories.
