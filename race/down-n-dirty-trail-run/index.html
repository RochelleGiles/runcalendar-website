Course

Both courses run on the rolling hill trails of Cameron Park, Waco, taking in named singletrack such as Powerline, Slinky, Mix Master and Vortex. The 8K run and 3K hike both start at 9:00am from the Northern Gateway Pavilion, where race-morning packet pickup is held.

About

The Down 'n Dirty Trail Run is the second race in the Huaco Cuatro Trail Run Series, staged by the Waco Striders in Cameron Park, Texas. Runners take on an 8K trail race or a 3K trail hike over the rolling wooded hills above the Brazos River.
