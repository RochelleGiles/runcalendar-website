About

Help Support the Irvington Booster Club! PLT is teaming up for the 2nd year with the IBBC for a very special trail 5k and kid's trail run with a portion of the proceeds going to the Irvington Bulldog Booster Club! This is a rain or shine event! Come out to the Irvington Woods for a beautiful trail 5k and a .6 mile (1k) kid's trail fun run (10 and under).
