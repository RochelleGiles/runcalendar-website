About

The Wicked Wine Run is a unique running event that combines the love of wine with the thrill of a race. Participants can choose between a 1K tasting walk or a 5K run/walk, both of which offer the opportunity to sample delicious wines along the course. The event also features an after-party with music, games, and more wine.
