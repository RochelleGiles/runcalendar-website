About

The Trail Des Portes De Meuse is a unique night trail running event that takes place in the scenic Meuse region of France. The course offers stunning views and a challenging terrain, making it a must-attend event for trail running enthusiasts. The event features several distance options, catering to runners of all levels, and promises an unforgettable atmosphere with post-race festivities.
