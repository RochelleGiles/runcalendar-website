Course

Marathon, half marathon, 12km and 6km are run as laps of a 6km loop course at Bibra Lake on flat running paths. All courses are stated to be AIMS certified and lap times are shown live on an event screen. Start times are 8:00am marathon, 8:05am half marathon and 9:00am for the 12km and 6km, with a 2:30pm cut-off for all events.

About

The Bibra Lake RunningWorks Festival is held at Bibra Lake in the southern suburbs of Perth. It offers marathon, half marathon, 12km and 6km events run as laps of a 6km loop on flat running paths, with courses stated to be AIMS certified and a 2:30pm cut-off for all races.
