About

The Groet Uit Schoorl Run is a must-experience event for runners seeking a scenic and challenging course. Set in the picturesque Dutch town of Schoorl, this race winds through stunning natural landscapes, offering runners a truly unique and memorable running experience. With a rich history and a reputation for exceptional organization, the Groet Uit Schoorl Run is a must-add to any runner's event calendar.
