Course

Closed-road 5k and 10k routes through countryside around Wythall Park in Worcestershire, which is the event base for the start and finish. Both courses are relatively flat and run without laps. A Families on Track 5k relay runs alongside the individual races.

About

This fun run is organised by Wythall Community Association, with support from Worcestershire County Council and Events of the North. The event wouldn't take place without the hard work and dedication of the many volunteers in Wythall.
