About

The Trail Blanc Jurassien is a winter trail running event held in Prémanon in the French Jura mountains. The event is notable for being accessible to handisports athletes, making it an inclusive winter trail running competition. The race has built a strong following with organizations like ASSAP 77 participating for multiple years.
