About

The Trail Des 7 Laux is a captivating trail running event set against the stunning backdrop of the French Alps. Runners will navigate a challenging course through rugged mountain terrain, offering breathtaking views and an exhilarating test of endurance. This event is a must-try for any trail enthusiast seeking an unforgettable alpine adventure.
