About

The 16th Annual Denver Veterans Day Run is a memorial 5K and 10K fun run to celebrate local Veterans, recognized as “Denver’s Run for Veterans Day.” It supports the Colorado Veterans Project's mission to empower Veterans through career advancement and entrepreneurship.[3]
