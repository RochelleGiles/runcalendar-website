Course

An out-and-back run almost entirely on the paved recreation path through Franconia Notch State Park. It starts and finishes at the Cannon Mountain base lodge, heading south to a turnaround near the Mount Pemigewasset trailhead. The path runs beside I-93 and the Pemigewasset River but stays separate from traffic, passing Echo Lake, Boise Rock, the Basin and Flume Gorge.

About

The Franconia Notch Half Marathon runs through Franconia Notch State Park in New Hampshire's White Mountains, passing beneath Cannon Mountain. The race benefits Adaptive Sports Partners, which supports adaptive recreation for people with disabilities.
