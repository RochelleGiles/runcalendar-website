Course

A certified 5K starting at 8:00 a.m. from Parking Lot L2 on the DMACC Ankeny Campus, 2006 S Ankeny Blvd. Kids' fun runs of 50 and 100 yards run alongside by age group. Strollers and leashed dogs start at the back of the field.

About

The DMACC 5K Walk/Run is an annual event held at the DMACC Ankeny Campus. The event includes a 5K walk/run as well as a kids fun run and fun zone.
