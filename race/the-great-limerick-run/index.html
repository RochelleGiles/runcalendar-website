About

The Regeneron Great Limerick Run in Ireland offers a distance for every runner, from beginner to elite. Winding through the historic streets of an ancient city, this scenic event celebrates the community's rich culture and vibrant spirit. Whether you're chasing a personal best or simply enjoying the journey, the Great Limerick Run promises an unforgettable running experience.
