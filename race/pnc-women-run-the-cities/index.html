About

PNC Women Run the Cities is a women's road race held each May in Minneapolis, starting and finishing at Minnehaha Falls Regional Park. Entrants choose a 5K, 10K or 10 mile course along the Mississippi River, and a kids run is held alongside. Proceeds support Girls on the Run Minnesota.
