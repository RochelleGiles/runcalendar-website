About

The Fun Run Pink: Gold Coast is a vibrant and inclusive running event that celebrates the spirit of the Gold Coast community. This event offers a scenic course that showcases the stunning natural beauty of the region, with participants enjoying the lively atmosphere and camaraderie of fellow runners. Whether you're a seasoned athlete or a first-time runner, the Fun Run Pink: Gold Coast is an event not to be missed.
