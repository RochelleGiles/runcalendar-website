About

The HBF Run for a Reason is a must-do event for runners in Western Australia, taking place in the heart of vibrant Perth. Offering 3km, 12km, and half marathon distances, this scenic run is a great way to challenge yourself while taking in the city's iconic sights. Whether you're an experienced marathoner or just starting your running journey, this event has something for everyone.
