About

The Columbus Cookie Run & Walk offers a full menu of distances, from a 1-mile fun run to the full marathon, alongside a 5K, 10K and half marathon, through Columbus, Ohio. Timed by USA Race Timing, it draws first-time runners and marathoners on the same course.
