About

The Waipa Fun Run and Walk is a picturesque community event set against the stunning backdrop of Cambridge, New Zealand. Runners and walkers of all ages and abilities can explore the scenic rural trails, with options for 5K and 10K courses. This family-friendly event is a great way to enjoy the outdoors and connect with the local community.
