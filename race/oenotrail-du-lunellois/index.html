About

The Oenotrail Du Lunellois is a charity running event that takes place in the Entre-Vignes region of France. The event features several trail running distances through the scenic vineyards, with the longer routes offering challenging elevation gains. Proceeds from the event go towards funding sports programs for those with chronic conditions and supporting the fight against illiteracy.
