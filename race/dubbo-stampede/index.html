Course

All courses start and finish at Ollie Robbins Oval in Dubbo. The World Athletics certified marathon and half marathon run anti-clockwise along the Macquarie River, pass through Taronga Western Plains Zoo and return on the river trails; the shorter events loop the river closer to town. Relatively flat, on a mix of sealed path and river trail.

About

Dubbo Stampede is a World Athletics certified running festival in central-west New South Wales, offering distances from a 1km fun run up to a full marathon. All courses start and finish at Ollie Robbins Oval, drawing a mix of local families and visiting runners each September.
