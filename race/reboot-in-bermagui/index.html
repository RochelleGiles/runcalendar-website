Course

All runs start and finish at Dickinson Park, Bermagui. The half marathon is a loop out to Camel Rock and Murunna Point returning via Old Tilba Road, mixing road, gravel, trail, coastal bush track and a short stretch of sand. The 10km is an out-and-back through town and along the wetlands to Haywards Beach, and the kids' 1.5km is a level paved course in the park.

About

ReBoot in Bermagui is a weekend running event on the NSW Sapphire Coast, with a 10km road run and a half marathon trail run that follows Bermagui's beaches and coastal headlands. The town is a popular base for South Coast holidaymakers.
