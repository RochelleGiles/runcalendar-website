About

The Islandeady Fun Run is a 5km and 10km charity run/walk held in County Mayo. Starting and finishing at Jack's Old Cottage, Derrycooraune, Islandeady, the 5km follows a scenic clockwise route, while the 10km covers two laps of the same course.
