About

The Wings for Life World Run in Perth is a unique global race where participants run simultaneously with others around the world. Taking place at Optus Stadium Park, this event features a 'Catcher Car' format where runners see how far they can go before being caught by a virtual pursuing vehicle. The event is fully accessible for wheelchair participants and supports spinal cord research.
