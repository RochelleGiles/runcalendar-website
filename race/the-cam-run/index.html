Course

About

The Cam Run is an annual running event in Chattanooga, Tennessee that includes a 5K race, a Kidz Run, and the Magnum Mile. The event is organized by the Chattanooga Track Club and is held to continue the legacy of Cameron Bean, a local runner who tragically passed away.
