Course

A backyard ultra run on a 6.7 km loop at Sandy Point, Invercargill, with a new lap starting on the hour, every hour, until one runner remains. The race is self-supported: assistance is not permitted out on the loop, only in the start area.

About

The Sandy Point Backyard Ultra is a captivating last one standing endurance race set in the picturesque Southland region of New Zealand. Runners will test their limits on a loop course in Invercargill, with the goal of completing as many laps as possible before being the last one standing. This unique event promises an unforgettable challenge for seasoned ultrarunners seeking a true test of their mental and physical fortitude.
