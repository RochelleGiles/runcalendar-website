About

The Kappa Delta Shamrock Run is an annual event hosted by Kappa Delta featuring a 5K run and 1-mile fun run/walk. It supports local children's charities and takes place in Ruston, LA, with sign-in at 7:30 am, 5K start at 8:45 am, and fun run at 8:30 am.
