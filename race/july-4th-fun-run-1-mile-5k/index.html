About

The July 4th Fun Run 1 Mile & 5K is a celebratory Independence Day race featuring a 1 Mile fun run and 5K. It takes place at Bicentennial Park in Aurora, OH with events starting at 8:00am for the 1 Mile and 8:30am for the 5K.
