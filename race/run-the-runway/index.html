Course

Run on an active runway at Chicago Executive Airport, a rare chance to cover paved airfield surface closed to traffic for the morning. Participants get close-up views of parked aircraft and aviation displays along the way. A 1-mile walk and a kids dash run alongside the 5K.

About

Run the Runway is a unique opportunity for runners, families and anyone interested in aviation to run/walk on an actual airport runway, learn about flying and get up-close views of aircraft. Strollers are welcome.
