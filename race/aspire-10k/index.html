About

The ASPIRE 10K is an annual running event that takes place in Plainview, New York. Participants can choose to run or walk the 10K (6.2 miles) course, which winds through suburban streets and rolling countryside. The event features a finisher medal, post-race refreshments, and a drawing for prizes.
