About

The Shamrock 'N Run is a 5K run/walk fundraiser hosted by the PHN Charitable Foundation at Laurel Technical Institute in Sharon, PA. Proceeds support childhood literacy initiatives including Reach Out and Read, Little Free Library, and healthcare scholarships.
