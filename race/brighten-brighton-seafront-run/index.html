Course

Flat coastal run starting from Hove Lawns and following the Brighton and Hove seafront promenade, passing the burnt-down West Pier and the i360 tower. Two routes: 10 miles (about 82m of ascent, 9:00am start) and 10.1km (about 60m, 9:15am start). Signed throughout with pink arrows and tape. Course cut-off 1:30pm.

About

The BrighTEN Seafront Run is a Brighton running event featuring a scenic 10-mile or 10K route along the iconic Brighton seafront. Suitable for runners of all levels, it combines a flat, fast course with sea views, making it a popular race in the South East.
