About

Catering for a wide range of competitors, the Australia Day Fun Run has two start points. For the more dedicated runners we have a 10km run which starts at Safety Beach; the second start point is a 5.3km Run/Walk aimed more towards children and families. Both events take you along the foreshore bay trail and finish at the Village Green in Rosebud. On finishing at the Village Green there is a flag raising ceremony and presentations for all place getters in each category of the fun run. Along with plenty of fun and free family activities held on the Village Green, the fun run is a must for all sporting enthusiasts as well as family and friends looking to celebrate Australia Day on the Mornington Peninsula.
