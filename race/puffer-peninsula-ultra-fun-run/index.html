About

PUFfeR (Peninsula Ultra Fun Run) is an ultra trail run along the Cape Peninsula's mountain chain in Cape Town, organised by Fish Hoek Athletic Club. It covers 65km of peninsula terrain, one of the region's long-standing point-to-point ultra trail runs.
