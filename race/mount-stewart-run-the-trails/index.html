About

Mount Stewart Run The Trails includes 5km and 10km distances, plus a kids' 2km. All races start from the front of the house, with the 5km and 10km run as one-loop courses around the trails and road paths within the Mount Stewart estate. It's an open event organised by Scrabo Striders.
