Course

Starts and finishes inside the La Trobe Sports Park precinct at Bundoora, passing the Home of the Matildas before heading out towards Darebin Parklands and returning via Nangak Tamboree. The 10KM covers two laps of the 5KM loop. A 5KM walk and a 1KM kids fun run run alongside.

About

Run La Trobe is a community 5km and 10km fun run looping through La Trobe University's Bundoora campus in Melbourne, with a 1km kids run alongside the main event and links to the university's sport programs.
