Course

All distances start in Ephram White Park, Bowling Green. The programme spans two days, with a Friday evening kids one-mile glow run and the half marathon, 5K run and 5K walk on the Saturday. A three-hour time limit applies to the half marathon.

About

The German American Run & Walk for Children is FEC's longest-running fundraising event, marking three decades of support for FEC's child abuse prevention programs. It features a half marathon, 5K run, 5K fun walk, and a free Kids One Mile Glow Run.
