About

The Matilda Bay Run is a community running event offering multiple distance options in a scenic location. Participants can choose between 10km and 4km routes, with a special Joeys Kids Dash for younger runners. The event provides a fantastic opportunity for runners of all levels to kick off the new year with an active and enjoyable morning.
