About

The Trail du Vélan is a thrilling trail running event set against the stunning backdrop of the Swiss Alps. Runners can expect a challenging course that winds through scenic mountain landscapes, offering breathtaking views and a true test of endurance. Whether you're an experienced trail runner or new to the sport, this event promises an unforgettable running adventure.
