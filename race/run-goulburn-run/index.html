About

Run Goulburn Run is an annual charity fundraiser fun run based at Marsden Weir Park, organised by BDCU Goulburn Fundraising. Participants choose from 1.5km, 5km and 10km distances. All proceeds go towards purchasing equipment for Goulburn Base Hospital.
