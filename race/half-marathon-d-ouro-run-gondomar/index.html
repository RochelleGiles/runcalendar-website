About

The Half Marathon d'Ouro Run Gondomar is a picturesque running event set along the stunning Douro River in the historic town of Gondomar. Runners can expect a challenging yet rewarding course that showcases the region's breathtaking natural beauty and rich cultural heritage. This event is a must-do for any distance runner seeking an unforgettable running experience.
