About

The Railroad Bridge Run is a 5K and 10K at Sequim, Washington, run on the Olympic Discovery Trail and organised by the Port Angeles Marathon Association as part of the Run the Peninsula series. Both distances are out-and-back routes from Railroad Bridge Park, crossing the Dungeness River railroad bridge. A virtual option is also offered.
