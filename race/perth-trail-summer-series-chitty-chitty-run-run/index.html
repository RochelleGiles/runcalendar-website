About

The Perth Trail Summer Series: Chitty Chitty Run Run is a popular trail running event that takes place in the beautiful natural surroundings of Western Australia. The course features stunning scenery and challenging terrain, making it a must-do for trail running enthusiasts. The event offers a range of distances to cater to runners of all abilities, from kids and teens to seasoned ultrarunners.
