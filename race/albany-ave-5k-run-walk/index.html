Course

A USATF-certified 5K road course starting and finishing at Albany Avenue School, 101 N. Albany Avenue, Massapequa. Run entirely on neighbourhood streets. A shorter fun run is also offered alongside the timed 5K.

About

The Albany Ave 5K Run/Walk is an annual event that raises funds for the Albany Avenue School PTA. All finishers receive a medal, and the event features refreshments, snacks, t-shirts, and a post-race awards ceremony.
