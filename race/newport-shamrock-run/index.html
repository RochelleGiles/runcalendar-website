About

The Newport Shamrock Run is a St. Patrick's Day themed race on the Oregon coast, starting and finishing at South Beach Marina in Newport. Runners choose between a half marathon, a 5K run or walk, and a 1K kids fun run, with the route passing beneath the Yaquina Bay Bridge. The half marathon offers an earlier start for walkers.
