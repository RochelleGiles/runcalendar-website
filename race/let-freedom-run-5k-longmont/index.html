About

The Let Freedom Run 5k - LONGMONT is a patriotic 5K run/walk event held on July 4th in Longmont, Colorado. It features a 5k Run/Walk and a Kids Fun Run of approximately 100 yards, with participants encouraged to dress as American heroes.
