About

The Capito Trail is a trail running event offering multiple distance options through scenic terrain. Runners can choose from 33km, 22km, and 12km routes, each with challenging elevation gains. The event features a unique nocturnal trail run and a kids' event, making it a comprehensive trail running experience for athletes of all levels.
