About

Cannonball Run is a timed looped ultra held at Broxton Bridge Plantation in Ehrhardt, South Carolina. Runners repeat a flat 3.2-mile loop for 6, 12, 24 or 34 hours, with a Last Man Standing format running alongside. The short, fast loop makes it a popular target for big mileage.
