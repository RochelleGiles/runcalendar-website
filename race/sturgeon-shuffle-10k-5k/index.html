About

Presented by First State Bank, the Sturgeon Shuffle is a family-friendly 5K walk/run and a 10K competitive road run open to all levels. Named after the spring sturgeon spawning run, both events start from New London Middle School and follow a fully chip-timed, out-and-back course on County Highway X along the Wolf River.
