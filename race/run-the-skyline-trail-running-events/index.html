About

The Skyline Mountain Marathon is a challenging trail race starting near North Fork Park in Liberty, UT, featuring steep climbs up Ben Lomond Peak and ridgeline running along the Skyline Trail. The event offers multiple distances including marathon, 55K, 30K, and half marathon, all finishing at Eden Park with stunning views of Pineview Reservoir.
