About

Run the Line is a fundraising race for the Dublin Wicklow Mountain Rescue Team (DWMRT) on 14 November 2026. The event consists of two courses - a 13km 'short' course and a 26km 'long' course. The routes start and finish in Glencullen Adventure Park and take runners across the Dublin Mountains with many spectacular locations along the way offering breath-taking views of Dublin.
