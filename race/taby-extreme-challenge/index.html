About

Taby Extreme Challenge (TEC) is an ultra running event featuring multiple distance options up to 200 miles. The race takes place in Tyresö with a challenging 11.5km loop course through beautiful natural surroundings. The event spans multiple days and includes both single-distance races and a backyard ultra format.
