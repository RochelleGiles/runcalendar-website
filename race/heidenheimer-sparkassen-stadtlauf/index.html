About

The Heidenheimer Sparkassen Stadtlauf is a must-run event for any avid runner. Set in the charming town of Heidenheim, this race takes participants on a scenic tour through the city's historic streets and stunning natural surroundings. With a well-designed course and a lively atmosphere, this event promises an unforgettable running experience.
