About

The Cincinnati Aruna Run is a charity event with 10K, 5K, and 1-Mile races held in Smale Riverfront Park, Cincinnati. It raises funds for the Aruna Project to free, employ, and empower human trafficking survivors, with 100% of fees supporting the cause.
