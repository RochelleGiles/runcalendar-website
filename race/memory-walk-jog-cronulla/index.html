Course

Start and finish at Don Lucas Reserve, Cronulla, with 3 km walk, 4.5 km walk/jog and 9.5 km run options. The site sits on a slight gradient towards the ocean and the course follows shared pathways, some sections of which are narrow.

About

Explore the scenic Cronulla coastline at the Memory Walk & Jog, a family-friendly event that combines fitness with fundraising. Set against the backdrop of Don Lucas Reserve, this unique run offers participants the chance to support a meaningful cause while enjoying the natural beauty of the Sutherland Shire.
