Course

A backyard ultra held at Frylands Wood Scout Outdoor Centre in Croydon, run on a four-mile forest loop with about 880 feet of climb. Runners set off from the same start each hour and repeat the lap until only one is left standing.

About

The London Backyard Ultra is a unique running event where participants run 4 miles every hour, on the hour, until only one runner remains. This challenging and endurance-testing format creates an exciting atmosphere as runners push their limits and support each other through the grueling competition.
