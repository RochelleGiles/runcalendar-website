About

The Light Night Glow Run is an electrifying evening event that combines fitness, fun, and vibrant energy. Participants of all ages can walk, jog, or run through a music-filled course while decked out in neon gear and glow accessories. This unique night run offers a memorable experience for families, friends, and fitness enthusiasts, culminating in an epic after-party under the stars.
