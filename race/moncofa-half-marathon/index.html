About

The Moncofa Half Marathon is a picturesque running event set in the charming coastal town of Moncofa. Runners can look forward to a scenic route showcasing the area's natural beauty, with stunning ocean views and a challenging yet rewarding course. This popular race is a must-do for any runner seeking an unforgettable half-marathon experience.
