About

The Demarest 5K is an annual running event held in Demarest, New Jersey, featuring a 5K race start at 9:30 AM EDT. It includes options like Demarest 5K Only and Principal's Challenge with family rates, followed by post-race refreshments, music, a Hero Fun Run, and awards.
