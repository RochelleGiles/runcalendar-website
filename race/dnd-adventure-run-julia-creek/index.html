Course

A lapped course starting and finishing at Kev Bannah Oval in Julia Creek, with outback-style obstacles set along the way on a challenge-by-choice basis — climb over, crawl under or go around. Roughly 45 minutes per 5km lap. The 10km and 15km are competitive and timed, the 5km is a fun run, and there is a 2km obstacle challenge for children.

About

DnD Adventure Run is the running event of the Julia Creek Dirt n Dust Festival, an outback multi-sport festival in North West Queensland. It is a trail-style adventure run through the Julia Creek surrounds.
