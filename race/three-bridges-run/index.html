Course

Run entirely on the sealed Parramatta Valley shared-use path along the Parramatta River in western Sydney. The route passes through George Kendall Riverside Park, Meadowbank Park, Rhodes Point and Newington Nature Reserve, with river views for most of its length. Longer distances cover the same path further upstream.

About

The Three Bridges Run winds along the Parramatta River, only 30 minutes west of Sydney CBD, taking in the sites of George Kendall Riverside Park, Meadowbank Park, Rhodes Point, and Newington Nature Reserve using the Parramatta Valley shared use path. With stunning river views showcasing the beauty of this area, it's one not to be missed.
