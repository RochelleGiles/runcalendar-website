About

The Fools Run 5K is an evening run through the scenic streets of Gig Harbor, WA. Set against the backdrop of the harbor at twilight, the event is designed to be playful, fun, and family-friendly, embracing a whimsical and lighthearted theme inspired by the spirit of April Fools.
