About

The Fat Turkey Run is an annual event that takes place in Ireland, supporting the Suttonians Rugby Football Club and the Irish Rugby Football Union Charitable Trust. Runners can enjoy a festive atmosphere and the opportunity to burn off some of those holiday calories on the scenic course. This unique event is a great way to get active and give back to the local community.
