Course

New Mexico's only point-to-point ultra trail race and the highest course in the state. The Sky Run 50K starts at Oliver Lee State Park in Dog Canyon near Alamogordo, the Cloud Run 32K from Sunspot, both climbing from desert floor to mountain ridge on high-elevation singletrack and historic rail-bed trail. Shuttles run from the shared finish pavilion to each start.

About

Cactus to Cloud Sky Race climbs from the Chihuahuan Desert floor near Alamogordo, New Mexico, into the high peaks of the Sacramento Mountains, with 32K and 50K sky-running distances gaining thousands of feet along the way.
