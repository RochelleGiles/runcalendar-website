Course

All distances start and finish at the Dover foreshore in far south Tasmania and follow the coastline of Port Esperance. About

The Dover Fun Run is held on the Dover foreshore in far south Tasmania and offers a 21km half marathon, a 10km Tassal Ten, a 5km walk or run and a 2km children event on a closed-road course. All distances start and finish at the foreshore and follow the coastline of Port Esperance. A virtual run option is also available.
