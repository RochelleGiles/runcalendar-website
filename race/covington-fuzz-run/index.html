About

Every year more than 3,000 runners, walkers, and spectators come to Covington for the Fuzz Run. Participants in the Run and See Georgia Grand Prix Series have named the Fuzz Run the "Best Race in Georgia" for four years. The Covington Police Department Fuzz Run is the largest participatory event in Covington, Georgia year after year. The Fuzz Run is a community event for all ages and all types of runners and walkers.
