About

The Bournemouth Bay Run offers runners a stunning seaside experience, with the event taking place along the town's famous seven-mile stretch of golden sand. Set against the beautiful backdrop of the Dorset coast, this picturesque race is a must for runners seeking an unforgettable and scenic challenge.
