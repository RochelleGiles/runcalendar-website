Course

A USATF-certified road course starting near The Hub at the corner of Center and Chestnut Streets in downtown Goldsboro. The route runs largely along streets lined with azaleas and dogwoods. A 10K, 5K run, 5K walk and one-mile fun run all set off at 9:00am.

About

The Greater Goldsboro Road Run - Run for a Child is one of the oldest road runs in North Carolina, held annually on a USATF-certified course. The route runs primarily along streets lined with azaleas and dogwoods, passing The Hub and the Streetscape improvements on Center Street.
