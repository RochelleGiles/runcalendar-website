About

The Cote Indigo Marathon is a scenic coastal running event that takes place along the picturesque Indigo Coast. Runners can expect a challenging yet rewarding course with stunning ocean views and a rich local culture. This annual race is a must-do for any endurance athlete seeking an unforgettable running experience.
