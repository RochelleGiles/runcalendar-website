About

MCAP Heroes on the Run is a 5K and one-mile fun walk at Norristown Farm Park in Norristown, Pennsylvania, entered via the Whitehall Road entrance. A virtual entry option is also offered. The event raises funds for the Montgomery Child Advocacy Project.
