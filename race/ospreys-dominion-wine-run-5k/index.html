About

The Ospreys Dominion Wine Run 5K takes place at Osprey's Dominion Vineyards on Long Island's North Fork, a 50-acre vineyard growing Carmenere, Pinot Gris, and Sauvignon Blanc grapes. The course loops through the vineyard rows for runners, walkers, and wine enthusiasts alike.
