Course

Loops through dense forest on the trail system at Dillon State Park near Zanesville, mixing flat grass-lined birding trails with technical single-track mountain bike trails. Routes run down the slopes towards Dillon Reservoir. The full loop set covers about 122 miles from a central start and finish village.
