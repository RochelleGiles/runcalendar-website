About

The DUbliNDEE Kilted 5K is now officially a USATF-certified race! This means, it is a road racecourse whose distance has been certified for accuracy. Race participants that run on a certified course allows them to accurately compare time to performances run on other certified courses because runners can be sure the distances were the same.
