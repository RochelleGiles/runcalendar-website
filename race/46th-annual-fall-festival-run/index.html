About

The Fall Festival Run is an affordable, family-friendly running event that takes place adjacent to the festival on Oregon State University's beautiful, tree-lined campus. Established in 1978, the trio of races (a 5K, 10K, and 1K Kids Run) are held on the Sunday morning of the Fall Festival weekend. Walkers are welcome.
