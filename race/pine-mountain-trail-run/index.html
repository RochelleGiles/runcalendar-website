Course

Loops of technical, rocky singletrack in F.D. Roosevelt State Park near Pine Mountain, an hour south of Atlanta, all starting and finishing at Liberty Bell Pool. The 19-miler is a single loop and the 40-miler repeats loops. Aid stations are run by GUTS volunteers, with crew access at the start/finish.

About

Pine Mountain Trail Run is a trail ultramarathon in F.D. Roosevelt State Park, Georgia's largest state park. Runners choose from 10K, 19-mile, 40-mile, and 46-mile distances across the ridge's rocky, rolling terrain in south Georgia's Pine Mountain range.
