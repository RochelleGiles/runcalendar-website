Course

The 10-miler is a challenging loop through the piedmont hills of Cumberland State Forest and Bear Creek Lake State Park. The Mini 4.2-mile run mixes park trails, Willis River Trail single-track and the Cumberland Multi-Use Trail. Both start and finish at Bear Creek Lake State Park.

About

The Richmond Road Runners Club hosts this trail race in Cumberland, Virginia, about 45 minutes west of Richmond. The route covers rooty, muddy terrain with several creek crossings and short climbs. A shorter 4.2-mile Mini run starts alongside it.
