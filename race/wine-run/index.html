Course

Starts and finishes at Rossendale Wines vineyard on Old Taitapu Road, Kennedys Bush, about seven minutes south of Christchurch. The 2027 route is a minimum of 5km with the option of a second lap for 10km, run around the vineyard with wine tastings roughly every kilometre.

About

The Wine Run at the Rossendale Wines Vineyard is a fun run/walk with a unique twist - wine tasting approximately every kilometre! The course features cheese and crackers at each station, with optional wine tasting. This is a non-competitive event for participants aged 18 and over.
