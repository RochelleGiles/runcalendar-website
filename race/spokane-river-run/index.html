Course

About

The Spokane River Run is a nonprofit trail running event held in Riverside State Park outside Spokane, Washington, offering races from 5K to 50K. It supports the Garfield A.P.P.L.E program through fundraising, with all entry fees directed to the cause and powered by volunteers.
