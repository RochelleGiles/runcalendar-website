Course

Four trail courses run inside the 3,000ha Tala Game Reserve near Camperdown, over rolling grassland and classic bushveld shared with kudu, giraffe and more than 380 bird species. Distances are 5km, 10km, 20km and 30km, climbing from about 102m to 784m, with one to four aid stations depending on the route. Starts are staggered from 06:00 to 07:30.

About

Tala Trail Run is a trail race held within Tala Private Game Reserve near Camperdown, KwaZulu-Natal, with distance options from 5km to 30km. Routes cross the reserve's game trails, home to rhino, giraffe and zebra.
