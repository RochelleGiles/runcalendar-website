About

The Foulees Vittelloises is an annual running event organized by ASSR Vittel Athletics. The event features multiple race distances for all age groups, from youth races to a 10K open race. The event includes a solidarity walk/run called 'LA VITTEL ROSE' and maintains a charitable component by donating €1 per bib to local associations.
