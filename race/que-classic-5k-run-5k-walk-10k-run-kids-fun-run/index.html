Course

All races are run at Quemahoning Dam near Hollsopple. The 5K is an out-and-back on the scenic dam road with gentle hills along the water; the 10K covers the same road, downhill for the first half and mostly uphill for the second.

About

The Que Classic redefines what a 5K should be…a beautiful race course, exciting atmosphere, friendly volunteers, great food and awesome goodie bags, it's no wonder we are considered by many to be the best fitness event in our region.
