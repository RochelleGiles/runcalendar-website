About

The Jackson Rose Run is a family-friendly running event celebrating 56 years, featuring multiple distance options including a 10-mile run, 10K, and 5K run/walk. The event takes place on the Jackson College campus with gently rolling hills and supports local soccer, cross country, and community organizations.
