Course

Three repeat loops of the Croom Hiking Trail in the Withlacoochee State Forest, through long-leaf pine and scrub-oak hills, creek bottoms and cypress ponds. Mostly single track under tree canopy. The 50K runs two loops and the 16-mile one loop.

About

This is a wonderful course that is mostly a great single track running trail that winds through outstanding Florida terrain and most of the trail even has tree canopy to keep off the sun. If you have never run this race, you need to experience one of the great places to run trails in Florida.
