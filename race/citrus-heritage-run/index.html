Course

Winds through the historic orange groves of California Citrus State Historic Park in Riverside, with views out to the surrounding mountain ranges. Hydration stops and live bands are placed along the route. Half marathon, 10K, 5K and a 1 mile kids run are offered.

About

The Citrus Heritage Run is an annual road race in Riverside, California, with half marathon, 10K, 5K, and kids' fun run distances. The event celebrates the city's history as an early hub of California's citrus industry.
