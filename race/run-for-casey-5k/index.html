Course

A USATF-certified, flat and scenic loop inside Nomahegan Park in Cranford, with a water station at about the halfway point. The loop suits runners and walkers alike, and a one-mile fun run is held for children aged ten and under.

About

This 5K Run/Walk at Nomahegan Park in Cranford, New Jersey, benefits The Sudden Unexplained Death in Childhood Foundation in memory of Casey Young. The event features a chip-timed 5K with medals for top finishers, a kids 1-mile Fun Run, and family activities.
