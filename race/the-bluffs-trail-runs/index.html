Course

Single-track trail courses through Echo Bluffs State Park and Current River State Park in Missouri, with rolling hills and 360-degree views from the bluffs. Distances run from a one-mile kids race up to a half marathon, which can also be run as a two-person relay.

About

The trail running experience you don't want to miss. Located in the most beautiful state parks in Missouri Echo Bluffs State Park and Current River State Parks. We offer something for the experienced trail runner to your first time running or hiking the trails.
