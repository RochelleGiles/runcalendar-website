About

The Foulées Brettevillaises is a captivating running event set against the picturesque backdrop of Normandy. Runners can look forward to a challenging course that winds through the charming town of Bretteville-sur-Ay, offering scenic vistas and a true test of endurance. Whether you're an experienced trail runner or new to the sport, this event promises an unforgettable experience for all.
