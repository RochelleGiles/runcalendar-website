Course

Out-and-back looped course built on 21.1 km laps, starting at Lyndoch and running along the Barossa Walking Trail (the Jack Bobridge Trail) to St Hallett Winery before reversing. Shorter distances use abbreviated loops and longer distances repeat them. Start and finish sit next to a winery, with the route passing along and through several vineyards.

About

The Barossa Run is an 'out and back, looped' course along the Barossa Walking Trail, also known as the Jack Bobridge Trail. The route starts at Lyndoch and continues to St Hallett Winery before returning, with participants running multiple loops for longer distances.
