About

The Neuse River Bridge Run is a road race in New Bern, North Carolina, offering a half marathon, 10K, 5K and a kids fun run. The longer courses cross the Neuse and Trent River bridges before finishing on the downtown waterfront. Proceeds support five local non-profit beneficiaries.
