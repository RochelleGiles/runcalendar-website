About

The Paluma Village Trail Run is held at Paluma, Queensland, with 6km, 10km and 20km courses plus a junior event. Courses start and finish at the Village Green and run on technical rainforest tracks in the Paluma Range, crossing creeks and slippery roots. It is the final round of the Outer Limits Trail Run Series.
