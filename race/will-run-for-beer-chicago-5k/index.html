About

The Will Run for Beer Chicago 5K runs a loop course on the Chicago lakefront in Lincoln Park, starting and finishing at the Diversey Harbor event grove. Finishers receive a bottle-opener medal and tasting glass for the post-race Brewfest, where local breweries pour for those aged 21 and over.
