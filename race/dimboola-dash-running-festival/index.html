Course

Start and finish are both in Dimboola, with the start line behind the Dimboola library. The course follows riverbank trails beside the Wimmera River and the organiser advises trail shoes rather than road shoes, as the path is narrow in parts. Aid stations sit at the 2.5km mark, the 5km mark and the 7km turnaround.

About

The Dimboola Dash runs on riverbank trails beside the Wimmera River, starting and finishing behind the Dimboola library. Distances run from a 2km kids dash up to a full marathon, and the organiser recommends trail shoes because the path is narrow and unsealed in places.
