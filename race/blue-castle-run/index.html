About

The Blue Castle Run is a scenic trail race centered around the iconic Blue Pool nature reserve in the Purbecks. The course features ancient woodland trails, hills and heath, ridges and valleys, offering runners some of the most stunning scenery in the area. The unique route includes special access to run around The Blue Pool itself, with laps at both the start and finish of the race.
