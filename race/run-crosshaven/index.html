About

Explore the picturesque coastal town of Crosshaven, Ireland during the annual Run Crosshaven event. This fast-paced road race features both 5km and 10km courses, offering a scenic challenge for runners of all levels. With its stunning ocean views and lively community atmosphere, Run Crosshaven is a must-do event for any distance enthusiast.
