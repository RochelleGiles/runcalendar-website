About

The Cali Marathon is a must-run event for any avid distance runner. Set in the vibrant city of Cali, the course winds through picturesque neighborhoods and offers stunning views of the surrounding mountains. With a rich history and a reputation for exceptional organization, this marathon promises an unforgettable running experience.
