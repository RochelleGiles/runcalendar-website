About

Run The Bridges is a fundraising event for Ballina Primary School, featuring a 10K race through the picturesque towns of Ballina and Killaloe. The scenic course takes runners across the old and new bridges, showcasing the beautiful natural surroundings. This community-driven event promises a fun and lively atmosphere, with local support cheering on participants of all abilities.
