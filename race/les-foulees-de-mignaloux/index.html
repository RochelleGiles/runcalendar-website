About

The Foulées de Mignaloux is a must-run event for any avid runner. Set in the picturesque town of Mignaloux, this race offers a challenging yet scenic course that winds through the local countryside. With a rich history and a welcoming community, this event is sure to provide an unforgettable running experience.
