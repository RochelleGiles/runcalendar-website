Course

Last-runner-standing backyard format on a 4.167-mile loop at Wilson State Park, Kansas, one lap started each hour until a single runner remains. Each lap opens with about three-quarters of a mile of pavement, the remainder on Switchgrass singletrack mountain-bike trail. The start/finish is the only aid station and the race is otherwise self-supported. Field capped at 100.

About

This is a true last-man-standing event, and it will go until there is only one runner left, no matter how long it takes. Unlike all other competition race formats, this one isn't about speed. It's about grit, determination, and pure will to finish another lap.
