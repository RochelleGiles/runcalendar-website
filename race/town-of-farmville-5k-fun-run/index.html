Course

Start and finish at Farmville Town Common, 3672 North Main Street. The route passes the town athletic field, golf course, library and arboretum and runs through historic and newer neighbourhoods. The 1.2 mile fun run covers the opening section then turns back. Surface and aid stations are not stated.

About

An annual community 5K race and fun run held in Farmville, NC, featuring a scenic course through the town's athletic field, golf course, library, arboretum, and neighborhoods. The event is chip-timed and includes a Fun Run option that follows the first 1.2 miles of the 5K course.
