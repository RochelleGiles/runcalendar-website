Course

Backyard-ultra format: a 6.71 km loop started every hour until one runner remains. Start and finish are at the same point in Victoria Park, Adelaide, where an aid station sits on the start line and is reachable every lap; runners may also set up personal supply tables. The loop is near-flat. No mandatory gear beyond a headlamp for night laps.

About

The No Time To Die Frontyard Ultra is a captivating last person standing endurance event set in the scenic trails and paths of Victoria Parklands, Adelaide. Runners will push their limits as they navigate this unique frontyard-style course, with the final finisher crowned the champion. This one-of-a-kind event promises an unforgettable challenge for seasoned ultrarunners.
