About

The REDDY Fun Run/Walk is a community run and walk at Pelican Park, Clontarf, on the Redcliffe peninsula north of Brisbane, raising funds through the Redcliffe Hospital Auxiliary. Waves start by distance from 6:30am, with 5km and 10km run and walk options alongside a half marathon.
