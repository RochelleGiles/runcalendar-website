About

Run Wild is a hybrid event featuring a 5K Run/Walk, 10K Run, and 1/3-Mile Smokey Bear Fun Run for kids ages 2-10. The event takes place at Potawatomi State Park and is organized by the Friends of Potawatomi State Park.
