Course

Single-track wooded trail run through Turkey Run in the Parklands of Floyds Fork, Louisville, Kentucky, with roughly 600 feet of elevation and some roots and rocks in the first mile. Offered as timed 5-mile and 3-mile runs; a paved path is used as a backup if trails are too muddy.

About

A trail running event through Turkey Run Park (Parklands of Floyd Fork) benefiting Second Chances Wildlife Center. Participants can choose between a 5-mile timed run or a 3-mile fun run, both on single-track wooded trails with approximately 600 feet of elevation gain.
