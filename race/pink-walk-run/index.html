About

The Pink Walk & Run is an evening fundraiser for the Breast Cancer Research Trust held at Innes Common on Hamilton Lake Domain. Participants choose a 3.8km walk around Hamilton Lake or a 5km run around the lake and Innes Common. The event opens at 4:30pm and the walk and run start at 5:30pm.
