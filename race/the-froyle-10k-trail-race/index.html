About

The Froyle 10K is a scenic countryside trail race weaving through rolling Hampshire fields, picturesque woodlands, and winding country paths. Runners will enjoy sweeping views of the South Downs and an enjoyable downhill finish. The event also features a fun Kids Colour Dash, making it a family-friendly running experience.
