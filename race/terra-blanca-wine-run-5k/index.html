About

The Terra Blanca Wine Run 5K is a two-lap course through the vineyard at Terra Blanca Winery and Estate Vineyard in Benton City, Washington. The route runs mostly on estate roads with some uneven ground underfoot. It forms part of the Wine Run 5k series.
