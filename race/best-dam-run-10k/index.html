Course

A USATF-certified, net-downhill 10K starting and finishing on 4th Avenue between Broadway and SE Main in Estacada, run mostly on private closed road with views of the Clackamas River, forest and geology along the way. Walkers set off at 8:45am and runners at 9:00am.

About

The Best Dam Run course is lovely! Mostly on private closed road, it features views of the Clackamas River, cool forests, interesting geology and (if you're lucky) bald eagles and osprey. The 10K is a speedy, net downhill point-to-point course, same as prior years.
