Course

A certified, professionally timed 5K through downtown Smithville, Tennessee. Starts on Church Street in front of the First Baptist Life Enrichment Center and finishes on Church Street near Love-Cantrell Funeral Home. The course stays open for 60 minutes. A one-mile fun run is also held.

About

The Fiddler 5K and One-Mile Fun Run is an annual Independence Day event held in Downtown Smithville, TN. It features a competitive 5K race and a family-friendly one-mile fun run starting at 7 am.
