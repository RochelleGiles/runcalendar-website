About

The Long Run features a roughly five-mile loop around Jacobsburg State Park, mixing gorgeous singletrack with flat, fast gravel trail and about 450 ft of elevation change. Runners can complete one loop or as many loops as possible within a 3- or 6-hour window. The event runs twice a year as Spring Forward and Fall Back, with the same course reversed each autumn.
