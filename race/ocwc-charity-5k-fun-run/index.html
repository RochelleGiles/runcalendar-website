Course

The 5K winds through the east side of Osprey Cove; the 1-mile fun run and family walk is a loop down Fairways Edge. Both start and finish at The Green Room Sicilian Cafe and Deli. The 5K runs from 9:00 to 11:00 a.m., the 1-mile from 9:15 a.m.

About

The OCWC Charity 5K & Fun Run is a charity event featuring a 5K run/walk and a 1-mile fun run & family walk. It starts and finishes at The Green Room Sicilian Cafe and Deli in Saint Marys, GA, supporting a charitable cause.
