Course

Technical trail running in the Grampians around Halls Gap, over rocky ridgelines, flowing singletrack and sandstone country. Saturday holds an 11km over The Pinnacle, a 6km Chatauqua Loop and a 2km kids trail; Sunday runs 50km, 30km and 20km on the longer mountain courses.

About

The Wonderland Run Grampians is a trail running weekend in the Grampians National Park featuring scenic trail runs through beautiful National and State Parks. Runners and walkers can choose from multiple distance options suitable for different skill levels.
