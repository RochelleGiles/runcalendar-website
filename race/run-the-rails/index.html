About

Run the Rails benefits the Elburn Parks Commission with a 1-mile fun run/walk, a 4-mile run and a 7-mile run, all starting and finishing at Prairie Park in Elburn, Illinois. The courses cross the Union Pacific West rail line via the Anderson Road bridge, with views over Elburn and the surrounding countryside.
