About

The Les Drayes Du Vercors is a thrilling trail running event set against the breathtaking backdrop of the Vercors Massif in southeastern France. Runners will navigate a challenging course through the region's dramatic limestone landscapes, offering stunning panoramic views and a true test of endurance. This event is a must-try for adventurous trail enthusiasts seeking an unforgettable mountain running experience.
