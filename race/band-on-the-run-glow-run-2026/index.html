About

Band on the Run is an evening glow-themed 5K run and walk in Perrysburg, Ohio, supporting the Perrysburg Junior High School band programme. The course starts and finishes at Second Sole in Levis Commons, with pep bands playing along the route. A shorter fun run is also offered.
