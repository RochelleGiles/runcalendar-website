About

The Run The Tan annual showcase charity event is back at the iconic Tan Track in Melbourne. There will be 5 key race events including a public fun run and feature events with elite athletes, celebrities, emergency service workers, and schools competing to set the fastest lap around The Tan while raising funds and awareness for Mental Health.
