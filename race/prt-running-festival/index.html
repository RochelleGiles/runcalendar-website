Course

Held at Rockland Lake State Park, car park 2, 299 Rockland Lake Rd, Valley Cottage, New York. The course is a single 5K loop: one lap for the 5K, two for the 10K and three for the 15K. Start and finish are the same for every distance and runners cross the line on each lap to record splits. Surface and aid station detail are not published.

About

The PRT Running Festival features 15K, 10K, 5K run/walk events and a kids run at Rockland Lake State Park in Valley Cottage, NY. It celebrates the anniversary of the Polska Running Team with finisher medals for the first 100 participants.
