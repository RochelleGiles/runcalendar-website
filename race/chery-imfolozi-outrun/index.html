Course

A two-day trail run inside the Hluhluwe-iMfolozi Game Reserve, the oldest game reserve in Africa, with a race village near the Centenary Centre in the eastern section. The Warthog option covers 11km on each day and the Rhino 20km then 11km, with day one away at 07:00. It is a Big 5 reserve, so the route is run with ranger checkpoints and helicopter support, and the field is capped at 300 runners.

About

The iMfolozi Outrun is a trail race through South Africa's Hluhluwe-iMfolozi Game Reserve in KwaZulu-Natal, with 22km and 31km distances crossing the reserve's bushveld and game trails.
