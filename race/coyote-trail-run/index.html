Course

Repeats of an 8.33 mile loop at Cleburne State Park, with 50 mile, 50K, 25K, 8 mile and 4 mile options off the same course. The loop is technical with steep climbs and 800 to 1,000 feet of gain. There is one aid station per loop plus the start/finish; the race is cupless, so runners carry their own hydration.

About

Coyote Trail Run is a trail race at Cleburne State Park near Ft. Worth, TX, offering distances of 50 miles, 50K, 25K, 8 miles, and 4 miles. The event features challenging terrain with steep climbs and beautiful scenery on mountain bike and hiking trails.[1]
