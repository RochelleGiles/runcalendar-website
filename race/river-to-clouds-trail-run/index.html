Course

Trail races starting at First Horizon Pavilion in Chattanooga and finishing at Ross's Landing, running toward Lookout Mountain. The 100-mile starts Friday, with the 50-mile and 27-mile 'Barely Ultra' on Saturday, plus a four-person 50-mile relay.

About

The Whiskey [Trail] Run is an exhilarating event that combines the thrill of trail running with the fun of a whiskey festival, set against the beautiful backdrop of Lookout Mountain and finishing at Ross's Landing. Whether you're an elite ultrarunner or a whiskey warrior, this event has something for everyone.
