About

The Deborah Rubano Stehlik Memorial 5K is held in memory of Babylon Crossfit enthusiast Deborah Stehlik, with all profits sponsoring a student scholarship. The 3rd annual event takes place at Belmont Lake State Park in West Babylon, NY.
