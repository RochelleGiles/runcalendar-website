Course

A 7.4 mile point-to-point from Mill Valley over the shoulder of Mount Tamalpais to Stinson Beach. The route opens with the Dipsea Stairs, three flights totalling 680 steps, and continues on steep, narrow and often rough trail. Runners start in handicapped groups by age and sex.

About

The Dipsea Race is a 7.4-mile point-to-point trail run from Mill Valley to Stinson Beach on California's Marin coast. It opens with nearly 700 steep steps before crossing fire roads and single track over the headlands to the Pacific. First run in 1905, it is the oldest trail race in America and uses a handicap start so any age can win outright.
