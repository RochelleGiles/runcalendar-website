Course

An untimed 5K fun run and walk starting and finishing at Town Square in downtown Grand Forks. Actors from the North Dakota Shakespeare Festival are stationed along the route delivering scripted Shakespearean insults to passing runners. A race clock and award categories are used, but there is no chip timing.

About

The Rude Run 5K is a themed race through downtown Grand Forks, North Dakota, put on by the North Dakota Shakespeare Festival. It pairs a run through Town Square with the festival's playful, theatrical spirit.
