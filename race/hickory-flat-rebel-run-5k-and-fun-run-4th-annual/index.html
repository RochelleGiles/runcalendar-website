Course

The 5K runs on streets through the town of Hickory Flat, starting and finishing at the school gym parking lot on Spruce Avenue. The one-mile fun run and walk uses the same start and finish area. No aid station or elevation detail is published.

About

The Hickory Flat Rebel Run is a community running event featuring a 5K run/walk and a 1-mile fun run through the town of Hickory Flat, MS. It offers awards for top finishers, limited edition t-shirts, and supports local initiatives with registration starting at 7:00 AM.
