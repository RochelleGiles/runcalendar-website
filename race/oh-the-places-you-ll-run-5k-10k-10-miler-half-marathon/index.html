Course

Out-and-back courses along the Long Beach beach path. The 5K and 10K share a route, with the 10K running two laps; the half marathon runs a 5-mile section twice plus the 5K route once. Runners keep to the pedestrian side of the shared path.

About

A themed run/walk event honoring Read Across America Day with multiple distance options. The race features a scenic start at Alamitos Beach in Long Beach with all runners receiving finishing medals.
