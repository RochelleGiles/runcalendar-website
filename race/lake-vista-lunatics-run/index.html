Course

Repeated 4.167-mile trail loop in southern Indiana, run as a timed 6-hour or 12-hour event with a single-lap fun run alongside. The loop climbs to a summit on grades of 25-30 percent, with creek crossings and technical root and rock sections before the descent. Runners return to a central crew area between laps.
