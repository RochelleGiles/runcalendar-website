Course

The 10K, 5K and walk all run out on Columbia city streets from Segra Park and finish inside the ballpark itself. Flat sealed roads, 8:10am start for the 10K and 5K. An 800m Aflac Kids Fun Run finishes at home plate.

About

The Famously Hot Pink 10K and 5K is Columbia, South Carolina's long-running breast cancer awareness race, held each October with the Prisma Health Midlands Foundation. It runs alongside the Walk for Life community walk as part of the same event weekend.
