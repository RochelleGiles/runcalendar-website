Course

A trail run held inside Golden Gate Highlands National Park in the eastern Free State, staged alongside a mountain bike challenge over the same weekend. Distances range from a 5 km fun run to 10 km, 25 km and 40 km routes through the park's sandstone highlands and grassland.

About

The Golden Gate Dino Trail Run takes place in and around Golden Gate Highlands National Park in the Free State, with distances from a 5km fun run to a 40km trail route. It's run in partnership with SANParks Honorary Rangers as part of the park's annual event calendar.
