Course

A clockwise loop of the Labillardiere Peninsula on Bruny Island, starting and finishing at Jetty Beach campground. The western leg follows a 4WD track above the D'Entrecasteaux Channel before dropping to Butlers Beach opposite Partridge Island, and the return is on single track along the eastern side back to the start.

About

The Labilladiere Peninsula Run is a trail run on Bruny Island featuring a clockwise loop of the Peninsula. Runners enjoy magnificent views of the D'Entrecasteaux Channel and Southern ranges, with a scenic route passing Partridge Island and Butlers Beach.
