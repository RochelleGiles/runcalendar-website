About

The Beechworth Beer Run is a running event that celebrates beer with a focus on the fine and many flavours this magical brewed liquid can be conjured into by master brewers such as those found at Bridge Road Brewers. The event features a 30km Full Pint run from Yackandandah to Beechworth, and a 15km Half Pint loop around Lake Sambell, both offering free beer at the finish line.
