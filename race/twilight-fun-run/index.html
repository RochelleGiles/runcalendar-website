Course

The 5K starts at Eulalona Park and follows the path running parallel to Crater Lake Parkway before heading up El Dorado and Daggett, then turning onto Bryant Williams Way and looping around the Oregon Tech campus. It finishes at the College Union near the main campus entrance. The route is paved throughout and open to both runners and walkers.

About

The Oregon Tech Twilight Fun Run is hosted by Oregon Tech Wellbeing in collaboration with the Student Veterans Program, and as part of community Memorial Day events, honors all fallen veterans.
