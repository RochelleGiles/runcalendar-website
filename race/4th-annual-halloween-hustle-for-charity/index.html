About

The Halloween Hustle for Charity is a costumed run in Glenwood Springs, Colorado, offering a 10K trail run/walk, a fully paved 5.5K and a 1.5K trick-or-treat fun run for children. It raises money for the local Advocate Safehouse Project and goes ahead rain or shine.
