About

The Two Bays Trail Run is an exhilarating ultramarathon through the stunning Mornington Peninsula in Victoria, Australia. Runners can choose between a challenging 28km or grueling 56km course, both offering breathtaking ocean vistas and diverse natural landscapes. This event is a must for trail running enthusiasts seeking an unforgettable adventure.
