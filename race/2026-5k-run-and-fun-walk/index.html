About

The AIA El Paso 5K Run and Fun Walk is an architecture-themed race through Downtown El Paso, organised by the local chapter of the American Institute of Architects. Runners pass landmark buildings along the route, which are described in a course booklet given to participants, and a one-mile fun walk runs alongside the 5K.
