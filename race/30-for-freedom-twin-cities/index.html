Course

The Twin Cities event is based at Cedar Valley Church, where a 5K loop on paved paths and local streets forms the building block for every distance. The 10K, half marathon and 30-mile ultra repeat that loop, so all four distances share one start and finish.

About

A community running event supporting the fight against human sex trafficking, with participants running/walking various distances to raise funds for rescue and restoration efforts. The event offers multiple distance options including 5K, 10K, half marathon, and 30-mile ultra marathon.
