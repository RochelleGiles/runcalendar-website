About

The Aon Mullingar Half Marathon is an annual running event set in the heart of Ireland's Midlands region. Runners can expect a scenic course through the charming town of Mullingar, offering a unique challenge and experience for both seasoned athletes and those new to the half marathon distance. This community-driven event is a must-do for runners seeking an unforgettable Irish running adventure.
