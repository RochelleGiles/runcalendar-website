Course

About

The New Albany Symphony Orchestra and IVIM Health are proud to present the annual New Albany Independence Day 5K Walk, Run & Family Races! In addition to the 5k the event also features the adorable 20-Yard Toddler Crawl sponsored by AcademyOne, 1/4 Mile Kids FUN Run sponsored by Maple Orthodontics and Pet Parade sponsored by Sandy Mendoza!
