About

The Countdown to ONE! Running Race Challenge takes place in Webster, near Rochester, New York, on a 1-mile loop course with the same start and finish for every lap. Runners complete as many single miles as they can within set time requirements, pushing themselves further each lap. All participants receive a finisher medal.
