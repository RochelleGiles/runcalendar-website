About

The 3rd Annual Feeney's 5K Fun Run and Virtual Run supports the Feeney Legacy Project in placing lifesaving billboards around Georgia with the message: Don't be a BYSTANDER. CALL 911. Be a LIFESAVER. The live event is held at Brook Run Park with post-run fun including food, DJ, vendors, and games.
