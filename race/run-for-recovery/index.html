Course

An evening 5K run/walk starting from lot 15 by the Superior Dome on Presque Isle Ave in Marquette. In-person registration opens at 5:00 PM and the event runs to 7:00 PM, with teams of four, six or eight entering alongside individuals.

About

The 18th Annual Run for Recovery is an awareness and fundraising event presented by Great Lakes Recovery Centers. The event includes a 5K fun run held in Marquette and other Upper Peninsula communities.
