Course

A lapped charity event run entirely inside Bute Park in central Cardiff, with all distances starting and finishing at Cooper's Field. Participants choose anything from a 5 km walk up to an ultra, with staggered start times through the day between 7:30am and 4:30pm. A virtual option is also offered.

About

The bigmoose Ultra Fun Run is a charity event through Bute Park in Cardiff, raising money and awareness for mental health support. It offers a range of distances from 5K up to marathon length, run in a relaxed, fun-run atmosphere.
