About

The Pirate Dash 5K & 1M Fun Run is a pirate-themed running event held at Founders Park in Wylie, Texas. It offers a timed 5K race and a 1-mile fun run open to participants of all ages and skill levels, with finisher medals for all and awards for top finishers.
