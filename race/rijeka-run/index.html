About

The Rijeka Run is an exciting annual running event that takes runners on a scenic tour through the historic city of Rijeka. Participants can enjoy breathtaking views of the Adriatic coast as they challenge themselves on a well-marked course. Whether you're a seasoned runner or new to the sport, the Rijeka Run offers an unforgettable experience for all.
