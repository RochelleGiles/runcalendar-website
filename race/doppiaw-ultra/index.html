About

The Doppiaw Ultra is a challenging trail running event set in the stunning Valtellina and Valposchiavo regions of Italy. Runners will experience breathtaking alpine scenery, testing climbs, and technical descents as they tackle distances ranging from 15km to the grueling 104km ultra. This event is a true test of endurance and a must-do for any trail running enthusiast.
