Course

Multiple course options through Riverhead pine plantation forest sharing common sections; short and mid start together and split at ANZAC Road, with longer courses extending further into the forest before all return to the event base. Surface is mostly clay track with metalled forestry road sections and mud. Staggered starts at 9am, 10am and 11am.

About

The Auckland Trail Run & Walk Series event at Riverhead Forest is part of an annual Winter series organised by Trail Events NZ. Each event offers multiple distance options in stunning locations within one hour of central Auckland.
