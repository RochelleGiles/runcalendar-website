Course

A USATF-certified 5K loop on sealed roads through Brightwaters, New York, starting and finishing at Walker Park. The course is flat and suits both runners and walkers, with a free fun run held beforehand.

About

The Bay Shore Engine Company Run to the Pump 5K Run/Walk & Fun Run is a community event that benefits the Bay Shore Engine Company No. 1, a volunteer fire service that has been serving the Bay Shore and Brightwaters area for over 100 years.
