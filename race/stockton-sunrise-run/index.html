Course

The Sunrise Run starts and finishes at Stockton Park, across the harbour from Newcastle. The coastal course runs flat along the Stockton foreshore, with half marathon, 14km and 7km options run as part of the Island Triathlon Festival weekend.

About

The Stockton Sunrise Run is part of the Island Triathlon Festival weekend. These events are held on a very flat course mostly on concrete paths along the Stockton Foreshore.
