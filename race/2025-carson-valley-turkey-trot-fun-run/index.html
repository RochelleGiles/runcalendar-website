About

Join us for the 9th Carson Valley Turkey Trot. This fun run takes place in the beautiful Carson Valley, starting at Minden Park in downtown Minden. Trot through this picturesque downtown neighborhood as a fun way to start the Thanksgiving holiday. In addition to the in-person fun run on Thanksgiving morning, children 12 and under can participate in the Turkey Dash or skip the in-person events altogether- and opt for the virtual race to run on your own schedule. If race is full, same day registration will be available. T-shirt and swag bag as available.
