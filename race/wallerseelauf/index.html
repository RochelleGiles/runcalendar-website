About

The Wallerseelauf is a scenic running event set in the picturesque region around Seekirchen, Austria. Runners of all levels can enjoy the scenic lakeside course, which winds through forests and meadows and offers stunning views of the Waller See. Whether you're looking for a challenging race or a scenic training run, the Wallerseelauf is an event not to be missed.
