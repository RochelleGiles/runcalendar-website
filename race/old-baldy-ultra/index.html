Course

Rocky, dirt singletrack in Garner State Park near Concan, run as repeats of a six-mile loop with about 1,400 ft of climb per lap. Start and finish are at a special event entrance to the park, not the main gate. The main aid station at the start/finish takes drop bags and crew; a second aid station at mile 2.82 serves the 10K loop only and has no crew access.

About

Old Baldy Ultra is a trail race at Garner State Park near Concan, Texas, climbing the park's landmark Old Baldy hill. Distances range from a 5K up to a 50K.
