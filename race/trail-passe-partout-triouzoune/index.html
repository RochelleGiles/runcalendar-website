About

The Trail Passe Partout Triouzoune is a running event that takes place in the beautiful Corrèze and Haute Dordogne regions of France. The course features stunning natural landscapes and challenging terrain, making it a must-do event for trail running enthusiasts. The event is supported by renowned athletes Nicolas VALENTIN and Baptiste VENTADOUR, adding to the excitement and prestige of the race.
