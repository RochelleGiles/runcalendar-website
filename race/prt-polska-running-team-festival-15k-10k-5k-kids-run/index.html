Course

Loop course starting and finishing at Rockland Lake State Park, Parking Lot 2, Valley Cottage, New York. One loop is 5K, with two loops for the 10K and three for the 15K; runners pass through the finish line on each lap for splits. A free kids fun run is also held.

About

The PRT Polska Running Team Festival is an annual road race weekend at Rockland Lake State Park in Valley Cottage, New York. It offers 15K, 10K and 5K events run over the same lake loop, plus a free kids fun run. Virtual entries are available for each of the timed distances.
