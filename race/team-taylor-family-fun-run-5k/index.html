Course

About

The 14th annual Team Taylor Family Fun Run is a 3-mile run through the beautiful streets of Arcadia in Phoenix, Arizona, benefiting Phoenix Children's Hospital. The event honors those impacted by SIDS and is open to all ages, with participants able to walk, run, bike, or scooter.
