About

Join us for a purr-fectly fun and meaningful morning at the Feral Fun Run — a family-friendly race event benefiting local Trap Neuter Return (TNR) efforts for community cats. Whether you're a dedicated runner or a casual walker, your support will help reduce the stray cat population and promote a humane solution for our feline friends.
