Course

All races start at Goleta Beach Park and run on dedicated, near-flat bike and running paths. The half marathon is a two-loop out-and-back mixing paved asphalt with about 1.3 miles of hard-packed soil path along Atascadero Creek; the return leg is paved. The 10K is a single out-and-back over the same segments, and the 5K is an out-and-back on paved bike path.

About

The Goleta Beach Half Marathon, 10K and 5K takes runners along the Santa Barbara coastline at Goleta Beach in Goleta, California. Racers choose from the half marathon, 10K, 5K or Kid's 1-Mile, all finishing near the beach.
