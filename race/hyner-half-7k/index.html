Course

Run in Sproul State Forest near Hyner Run State Park on rugged singletrack. The 14 mile main event climbs around 3,000 ft with three aid stations at miles 4, 8 and 11.5 and a strict six hour limit. The 7K takes the first big climb up Long Fork, runs to the deer fence and drops down Log Hollow to finish. Entry is capped at 225.

About

A 14-mile trail race in the heart of the PA Wilds. This course consists of some of the most beautiful and rugged single-track in Sproul State Forest. This event is open to runners/speed-hikers only and has a strict 4.5 hour time limit. By popular demand, a 7K option is now offered.
