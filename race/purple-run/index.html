Course

Run on the History Walk paths at Sunset Regional Park in Las Vegas, starting and finishing near the Dunes Overlook. The paved course is completely removed from vehicle traffic and is mostly flat with only slight inclines. The 5K is a single 3.1-mile loop; the half marathon repeats the loop three times.

About

The Purple Run is a tribute event to musician Prince, held at Sunset Regional Park in Las Vegas. The course runs along the park's History Walk paths near the Dunes Overlook.
