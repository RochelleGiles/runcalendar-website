About

The Hermes Westlake Spring Fever is a community running event held in Westlake, Ohio, featuring multiple race distances. The event includes a 4 Mile Run, 2 Mile Run/Walk, 1 Mile Fun Run, and a Kids Dash, along with a pancake breakfast.
