Course

An 8km coastal course at Kahawai Point on Glenbrook Beach, taking in headland views and sections of native bush. The 5km kids' run and community walk follow a shorter version of the same route, with the 8km starting at 10:00am and the shorter events shortly after.

About

The inaugural Kahawai Point Coastal Classic on 4 October 2026 is a community run showcasing this stunning coastal area. With an 8km run, 5km walk and Kids' 5km event, there is something for everyone.
