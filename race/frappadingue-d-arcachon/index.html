About

The Frappadingue d'Arcachon is a must-try running event set against the stunning backdrop of the Arcachon Basin in southwestern France. Runners can look forward to a challenging course that winds through picturesque coastal landscapes, offering breathtaking views of the Atlantic Ocean. This unique event is a favorite among endurance athletes seeking an unforgettable running experience.
