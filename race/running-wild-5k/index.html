About

A 5K run in Coward, South Carolina, raising funds for the Black Creek Wildlife Center, a volunteer-run non-profit working in wildlife education, conservation and rehabilitation. The race follows the same route as the local Run for Brighter Days 5K, and the organisers state it is run on roads rather than trail.
