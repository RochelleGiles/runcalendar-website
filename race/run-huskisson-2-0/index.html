Course

A fast, flat coastal course starting and finishing at White Sands Park on Beach Street, Huskisson, run alongside the Shimano Husky Triathlon Festival weekend in Jervis Bay. Distances run from a 2.5km fun run through 5km, 10km, half marathon and marathon to a 64.4km ultra. The organiser publishes no detailed surface or aid station breakdown.

About

Run Huskisson 2.0 returns to the picturesque coastal town of Huskisson, Australia, with an expanded lineup of running distances to challenge athletes of all levels. From the grueling Ultra to the family-friendly 2km, this event has something for every runner, all set against the stunning backdrop of the region's natural beauty.
