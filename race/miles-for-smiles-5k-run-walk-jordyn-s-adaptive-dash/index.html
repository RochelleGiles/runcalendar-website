Course

Based at the North Area Athletic Complex in Arvada, Colorado. The main event is a 5K run or walk, alongside Jordyn's Adaptive Dash, a free 50-yard finish-line dash for children using adaptive equipment. The organisers publish no detail on the route surface or shape.

About

Since 2007, Miles for Smiles 5K has not only been a fun race for competitive runners, it's been a great event for families wanting to share a great outdoor experience.
