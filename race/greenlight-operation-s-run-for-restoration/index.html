About

Greenlight Operation's Run for Restoration is a 5K and fun run staged on City Island in Harrisburg, Pennsylvania. The 5K uses a certified course, with check-in from 8:30am and a 9:00am start. Proceeds support the host organisation's work with human trafficking survivors.
