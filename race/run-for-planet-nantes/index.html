About

The Run For Planet Nantes is a community-driven running event that celebrates the beauty of the planet and raises awareness about environmental conservation. The event features a scenic 10km course through the Parc de la Chantrerie, offering runners a chance to connect with nature while supporting local sustainability initiatives.
