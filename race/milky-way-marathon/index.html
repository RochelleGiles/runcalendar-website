Course

A night trail run starting and finishing at Drie Kuilen Nature Reserve, run as a loop through remote Karoo wilderness. The route mixes jeep track with flowing singletrack. Two distances are offered, 42 km and 21 km.

About

The Milky Way Marathon is a night trail race through the Karoo near Touws River, run under some of South Africa's darkest skies on half marathon and marathon distances.
