Course

The races run on Cliff Drive, a Missouri state scenic byway through Kansas City's Historic Northeast, starting near the east entrance at 4439 Gladstone Blvd. The 8K, 5K and one mile follow the byway through autumn foliage, with a 200 m kids run alongside.

About

The Cliff Hanger Run in the Historic Northeast is a Kansas City classic! Run on Cliff Drive, a Missouri state scenic byway, while enjoying the crisp fall air, and beautiful foliage. All runners and 1 mile walkers will receive a Cliff Hanger Shirt, Finisher medal, custom bib, free photos and treats after the race!
