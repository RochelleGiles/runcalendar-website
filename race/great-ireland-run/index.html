About

The Great Ireland Run is a must-attend event for runners of all levels in the heart of Dublin's stunning Phoenix Park. This annual 10k race showcases Ireland's breathtaking natural beauty, with a course winding through the park's lush greenery and historic landmarks. Whether you're chasing a personal best or simply enjoying the vibrant atmosphere, the Great Ireland Run promises an unforgettable running experience.
