About

La Montliardaise is an annual running event held in Moulidars, France. The event features several trail running courses ranging from 9km to 39km, as well as a free-paced walking event. The event has grown in popularity over the years, attracting over 1,000 participants in recent editions. The challenging yet scenic courses and the welcoming atmosphere make this event a must-try for trail running enthusiasts.
