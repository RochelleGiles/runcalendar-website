About

The Manila Madness 5K Freedom Run/Ruck honors the legacy of Gunnery Sergeant John Basilone and the sacrifices of nation's heroes. It features a USATF-certified 5K run for all levels and a challenging 5K ruck simulating Basilone's combat load of approximately 100 pounds.[1]
