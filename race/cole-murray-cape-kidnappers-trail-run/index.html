About

The Cape Kidnappers Trail Run offers an amazing off-road adventure through private land not normally accessible to the public. The course features diverse terrain including windswept beaches, native forest, waterfalls, river gorges and stunning coastal farmland. Set at Te Kauwae-a-Maui / Cape Kidnappers, participants experience spectacular views across rolling hills, dramatic cliffs and endless horizons.
