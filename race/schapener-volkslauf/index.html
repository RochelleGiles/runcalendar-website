About

The Schapener Volkslauf is a running event that takes place in Schapen, Germany. The event offers several race distances, including a 10.5 km run, a 6.1 km run, and a 1.2 km run for children and youth. The course takes runners around the Riddagshäuser Teiche and through the Buchhorst forest.
