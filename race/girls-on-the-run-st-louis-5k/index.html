Course

A 3.1-mile course held entirely within Forest Park. Staggered wave starts reduce crowding, and the event is chip-timed from the start mat to the finish mat. It is run as a celebratory, non-competitive finish to the programme season, with participants free to walk, roll, push or run.

About

Each season comes to an end with a celebratory 5K. This closing event gives program participants of all abilities a tangible sense of accomplishment. Crossing the finish line instills confidence through completion and is a joyful moment program participants always remember!
