Course

Loop courses inside the Longmore Forest Reserve, all starting and finishing at Longmore Forestry Station where the race village is set up. The running is on logging roads, old forestry roads and jeep tracks with regular singletrack sections and some steep ascents and descents. Fully stocked checkpoints sit roughly 16 km apart, with drop bags allowed at set points on the longer distances.
