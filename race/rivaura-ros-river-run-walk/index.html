About

This family friendly 5K will start at Rivaura's beautiful Event Barn located inside the South Vineyard. Participants will run through the vineyard before running West onto Hewett Road headed towards Spaulding Park. About half way down there will be a turnaround point. Racers will follow the same route and eventually return back through the vineyard, finishing at the Event Barn.
