About

The REWE Women's Run is a vibrant running event exclusively for women held in Hamburg. Participants run along the beautiful Außenalster, creating a supportive and empowering atmosphere. The event offers not just a race, but a comprehensive experience with additional activities and a special Girl's Run for young female runners.
