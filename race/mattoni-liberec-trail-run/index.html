About

The Mattoni Liberec Trail Run is a scenic trail running event set in the beautiful natural surroundings of Liberec, Czech Republic. The 22km course takes runners through forests, meadows, and along picturesque trails, offering a challenging yet rewarding experience for participants. With a focus on sustainability and community, this event provides an opportunity for runners to connect with nature and fellow enthusiasts.
