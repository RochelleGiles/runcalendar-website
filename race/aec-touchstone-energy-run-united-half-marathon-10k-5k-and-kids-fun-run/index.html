Starts in the Newberry Street festival area in downtown Aiken, South Carolina, and runs out through the town including a stretch of South Boundary beneath its live oak canopy. Half marathon, 10K, 5K run/walk and a one-mile kids fun run all start from the same festival area.

About

The AEC Touchstone Energy Run United is an annual running event in Aiken, South Carolina that features a half marathon, 10K, 5K, and kids' fun run. The event is a fundraiser for the United Way of Aiken County.
