About

The Prealpes Trail Du Mouret is a must-experience trail running event set against the stunning backdrop of the Swiss Préalpes. Runners can expect a challenging yet rewarding course through picturesque alpine landscapes, with breathtaking views around every turn. This event is a true test of endurance and a celebration of the great outdoors.
