Course

Out-and-back courses from the base of the Steamboat ski area. The 50M climbs Mount Werner then follows singletrack, rough two-track and access roads to a Rabbit Ears turnaround, with aid at Mount Werner, Long Lake, Base Camp, Dumont Lake and Rabbit Ears. The 100M covers about 101.5 miles with 20,391 feet of ascent via Buffalo Pass and Emerald Mountain.

About

The Run Rabbit Run is an annual ultramarathon event held in Steamboat Springs, Colorado. The race features 50-mile and 100-mile distances, with both a Hare and Tortoise start for the 100-mile race.
