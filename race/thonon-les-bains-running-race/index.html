About

The Thonon Les Bains Running Race is a must-attend event for runners seeking a scenic and challenging course. Set against the stunning backdrop of the French Alps, this race winds through the charming town of Thonon-les-Bains, offering participants breathtaking views and an unforgettable running experience. Whether you're a seasoned marathoner or a recreational runner, this event promises an unforgettable day on the roads.
