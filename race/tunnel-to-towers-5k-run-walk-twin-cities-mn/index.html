About

The Twin Cities edition of the Tunnel to Towers 5K Run and Walk is held each spring at the Dakota County Fairgrounds in Farmington, Minnesota. It raises money for the Tunnel to Towers Foundation, which supports families of fallen and catastrophically injured first responders and military personnel.
