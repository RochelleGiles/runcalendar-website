Course

Starts and finishes at Brook Run Park, 4770 N Peachtree Rd, Dunwoody. The wheelchair 5K sets off at 8:00 AM, the 5K run at 8:05 AM and the one-mile fun run at 9:00 AM. A course map is published as a PDF.

About

The Lekotek Run is an annual 5K and one-mile fun run at Brook Run Park in Dunwoody, Georgia, raising funds for Lekotek of Georgia, which supports children with disabilities through play. The 5K is a certified course and includes a wheelchair division.
