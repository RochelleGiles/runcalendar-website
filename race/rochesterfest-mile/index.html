Course

A one-mile road race run on the Rochesterfest parade route, starting about 15 minutes before the parade. The venue is given as Soldiers Field Memorial Park, Rochester. No aid stations are provided at this distance. The organiser has run the race on a track in some past years, so the venue can shift.

About

The Rochesterfest Mile is a one-mile track race held on the Soldiers Memorial Field track in Rochester, Minnesota. Organized by the Rochester Running Club, it runs as part of the citywide Rochesterfest celebration each June.
