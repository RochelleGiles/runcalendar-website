About

The DINO Trail Run takes place in Mounds State Park near Anderson, Indiana, home to a group of ancient Native American ceremonial earthworks along the White River. Runners choose between 5K and 15K trail distances through the park's wooded terrain, part of the DINO Trail Run Series.
