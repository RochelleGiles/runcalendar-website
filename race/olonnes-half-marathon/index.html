About

The Olonnes Half Marathon is a scenic coastal running event set against the beautiful backdrop of the French Atlantic coastline. Runners can look forward to a challenging yet rewarding course that winds through charming seaside towns, offering stunning ocean views along the way. This long-standing race is a must-do for any runner seeking a memorable half marathon experience.
