Course

Hilly road course on public roads around Saltash, including single-track lanes where runners keep to the left. The half marathon, 5K and 1.8 mile fun run all start and finish at Longstone Park, where refreshments and entertainment run through the day. The organisers note the course is not suitable for wheelchair athletes.

About

The Saltash Half Marathon is one of the oldest and toughest half marathons in the United Kingdom, organised by the Tamar Trotters in south-east Cornwall. The hilly route mixes town streets with country lanes, and a 5K and a 1.8 mile fun run are held alongside it.
