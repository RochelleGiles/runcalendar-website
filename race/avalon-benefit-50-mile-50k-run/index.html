About

The Avalon Benefit 50 Mile/50K Run crosses Santa Catalina Island's rugged interior, starting and finishing in Avalon. Runners climb the island's backbone fire roads for sweeping views of the Pacific, with proceeds benefiting Catalina Island Health.
