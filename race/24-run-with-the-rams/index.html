About

The 24 Run with the Rams is a community event that welcomes runners and walkers of all ages and abilities. The event features a 1 Mile run and a 5K race, with awards for top finishers in various age groups. A portion of the proceeds will benefit a local community member or family in need, as well as the Clarke Athletics program.
