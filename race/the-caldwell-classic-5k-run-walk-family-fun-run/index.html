Course

Starts at James Caldwell High School, climbs Westville Avenue through a park past a pond, then returns along Brookside Avenue to the school. An all-road course with water stations every mile. The untimed 1-mile fun run does two loops from the same start and finish via Woodmere Road and Lane Avenue.

About

An annual memorial 5K run/walk honoring Theresa DiMasi and Marie LanFrank, organized by the Caldwell-West Caldwell Education Foundation. The event includes a timed 5K run/walk and a 1-mile family fun run for all ages.
