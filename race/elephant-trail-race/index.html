About

The Elephant Trail Race is a multi-day trail running event based at Port Macquarie on the New South Wales north coast, using tracks through Cairncross State Forest and surrounding bushland. Distances run from 13km up to a 217km ultra, with 25km, 50km, 100km and 160km options in between.
