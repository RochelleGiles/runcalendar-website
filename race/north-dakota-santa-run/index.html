Course

Flat 5K run or walk through downtown Mandan, starting and finishing on Main Street next to Dykshoorn Park. The evening route (4pm start) is lit by the Mandan Holiday Lights display.

About

The North Dakota Santa Run is a festive 5K event where participants 13 and older run or walk in Santa suits through downtown Mandan. It supports the fight against addiction and is organized by Visit Mandan and Mandan Progress Organization.
