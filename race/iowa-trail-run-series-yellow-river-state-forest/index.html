About

The Iowa Trail Run Series event at Yellow River State Forest offers scenic trail running on varied terrain with beautiful views of the Yellow River. It features 5K, 10K, and Half Marathon distances suitable for all abilities, starting at 7AM for the half, 9AM for 10K, and 10AM for 5K.
