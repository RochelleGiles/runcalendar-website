About

The Free to Run Trail Races use a double-loop singletrack course through Pittsfield State Forest, with distances from 5 miles to 50K. The 50K climbs roughly 6,000 feet. Proceeds benefit Free to Run, a nonprofit supporting women and girls in conflict regions.
