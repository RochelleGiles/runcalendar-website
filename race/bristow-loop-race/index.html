Course

A repeated 1.05-mile loop in Elijah Bristow State Park, almost entirely on trail, with a short paved section approaching and leaving the aid station, timing and parking area. Participants pass the single aid station every lap; it stocks gels, electrolyte drinks, food and hot meal options.

About

The Bristow Loop Run is a timed loop race that lets runners challenge themselves to see just how many miles they can run in a set time limit. The course is a 1.05-mile, almost all trail, loop through Elijah Bristow State Park, just 30 minutes east of Eugene, Oregon.
