About

The inaugural Run to the Rhythm Trail 5K & 1-Mile Fun Run/Walk is a scenic trail event at Northwood High School in Pittsboro, NC, inviting runners, walkers, families, and music supporters. It features a 5K trail race and a 1-Mile Fun Run/Walk for participants of all ages and abilities.
