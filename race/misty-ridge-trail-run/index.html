About

Misty Ridge Trail Run is a trail running event on Sterkspruit Farm near Lydenburg in Mpumalanga, close to the scenic Long Tom Pass. Runners can choose from distances ranging from 6.5km to a full 42km marathon across the farm's varied terrain.
