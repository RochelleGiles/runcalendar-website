Course

A flat, fast 5K run or walk on the Legacy Trail through Coldstream Park in Lexington, starting from 1850 Pisacano Drive, with a quarter-mile kids dash alongside it. Proceeds go to the Snow Bunny Baby Project, which supplies basic goods to families with babies in NICUs across Kentucky and Ohio. A virtual option is offered.

About

The Run Baby Run 5K is a family-friendly run/walk event benefiting NICU babies through the Snow Bunny Baby Project. It features a scenic 5K route at Coldstream Park in Lexington, Kentucky, along with a Kids' Dash.
