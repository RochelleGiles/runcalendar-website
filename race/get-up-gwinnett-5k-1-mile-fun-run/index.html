About

The Get Up Gwinnett 5K and 1-Mile Fun Run are held at Alexander Park in Lawrenceville, Georgia, raising funds for Young Life's youth ministry at Brookwood and Parkview High Schools. The 5K runs on paved park roads with an untimed one-mile run alongside it.
